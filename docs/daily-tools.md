# 日常小玩具

首页有两个入口，顶部「小玩具」菜单也可以进入。

本文件记录网页阶段的工具行为，不能直接作为当前小程序的界面规范。小程序说明见 [miniprogram.md](miniprogram.md)，最新已确认设计见 [Design.md](../Design.md)；修改网页时还需核对网页当前实现。

## 今天吃什么 `/eat`

- 初始有 26 道示例餐食；价格与准备时间是可编辑的示例值。
- 问答按餐次、辣度、预算、等待时间筛选，另有无肉（可含蛋奶）选项。
- 只从符合所有条件的餐食中随机选择。没有结果时提示调整条件或增加餐食，不会偷偷放宽要求。
- 可以换一道、确认选择。展开「我的餐单」可搜索、新增、编辑、移除与撤销移除。
- 后续提供常吃的餐食、店名、价格、等待时间等，即可替换示例餐单。

## 每日提醒 `/daily`

- 默认录入图片中的 24 件事：健康 9、精神 3、学习 6、健身 4、饮食 2。
- 一次展示一件事，点击「换一张」随机翻看，一轮内不重复；可回到上一张、按分类筛选、只看未完成。
- 22 种与事项关联的 SVG 动效，例如运动、音乐、刷牙、摄影、笔记等。相同活动共用对应的动画。
- 「今天做过了」记录当日完成，也可撤销；下方显示最近七天，按浏览器当地日期换日，保存最近 90 天记录。
- 「管理提醒」可新增、编辑、停用或恢复事项，选择分类、关联动效和专注分钟数。
- 四项默认番茄钟为 25 分钟，支持开始、暂停、继续、结束；计时结束不会自动打卡。当前计时保留到离开该页面为止。
- 补剂及褪黑素条目来自用户提供的清单，只记录个人既定安排，不生成用量或使用方案。
- 页面离开视口/后台时暂停场景动画，系统开启减弱动态效果时显示静态插画。

## 保存方式

游客的餐单、提醒、完成记录保存在当前浏览器。登录后使用当前账号自己的数据；游客数据不自动写入账号。

账号数据使用 `GET/PUT /api/personal-tools/{meals|reminders}` 保存到 SQLite，按读者/管理员及账户 ID 隔离。写入需 CSRF，内容最多 128 KB。离线写入会暂存在该账号的浏览器缓存，可在连接恢复后重试。无法确认身份时暂停写入，避免把个人数据误存为游客数据。

增量迁移 `20260909044205_PersonalToolState` 仅增加 `PersonalToolStates` 表，API 启动时自动迁移。

## 验证

网页和 API 正在运行时，在 `web` 目录执行：

```powershell
node scripts/check-daily-tools.cjs
npm.cmd run build
```

浏览器脚本使用独立游客环境，覆盖分类数量、22 场景、无重复翻页、完成/撤销/刷新/换日、自定义提醒、计时结束、选餐组合条件、换一道、餐单增删恢复、空餐单，以及 320/390/768/1440 宽度和减弱动画模式。

后端隔离集成测试，在项目根目录执行：

```powershell
dotnet build backend/Ottlog.Api -c PersonalTools
.tools/python/python.exe scripts/personal-tools-test.py
```

测试使用临时数据库，覆盖账户和工具隔离、CSRF、输入限制、迁移和重启持久化。
