# 选境与网页入口

网页日常工具现与小程序共用业务页面、表单和模型，入口与验收见 [网页同步](web-parity.md)。原选境保留在 /choose，选项首页在 /options；文章、账号与个人空间继续使用原网页入口。

2026-10-30 网页账号菜单在「账号设置」下方提供「登出」，桌面入口与窄屏导航复用 AccountMenu，菜单项保持等宽、等高。菜单及账号页共用 logoutAccount，经原同源 Cookie／CSRF 接口退出，成功后通知页面更新账号状态；提交中防重，失败保留菜单及重试入口，不清除工具业务缓存。

2026-10-22 用户要求删除网页的「吃什么」及「餐单与游戏」。专属食选比较、问答目录、小游戏、旧餐食和营养编辑界面以及失效测试已删除；/eat 与 /eat/legacy 均重定向至 /meals。饮食记录和常用餐单继续在同一个饮食页面使用共用实现，没有创建第二份餐食数据。

旧 dining 存档模型和后端接口继续保留兼容，不删除或迁移已有数据。meal-data.ts 保留原餐食、营养与备份格式校验；已退役界面不会再次读取或生成选择记录。

## 选境规范

用户明确命名为 option / options 的功能复用 web/src/components/option-field.tsx，沿选境的颜色、图形、分区几何、键盘方向键和 Enter、焦点、点击扩散与减少动态效果支持。

选境色块铺满视口。顶部进度按真实已答题数显示，已完成与当前步骤分别标色；最多十步每步一格，更多步骤按十个百分比区间显示。点击进度和两侧箭头只能到达已可访问步骤。浏览历史保留原答案，修改答案清除依赖后续历史，重复原答案保留后续进度。

## 验证

- node scripts/check-option-navigation.cjs：使用本机隔离 API 响应验证原选境的可达进度、前进返回与答案历史，覆盖 1440×1000、390×844、360×640。
- node scripts/check-choice-experience.cjs：原选境完整回归。
- npm.cmd run test:tool-workspace：日常工具的共用页面、编辑、餐食与数据兼容回归。
- node scripts/check-tool-backup-model.cjs：旧餐食及其他工具备份兼容校验。
- npm.cmd run build：生产构建与类型检查。

浏览器回归使用隔离上下文。check-dining-api.cjs 仅用于旧存档后端兼容测试，必须对独立测试 API 的 5237 端口和独立 Data__Directory 运行，不得对日常数据目录运行。
