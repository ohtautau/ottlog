# 日常 options 网页

首页 `/` 直接展示常用功能的选境色块。今后特意标为 option / options 的功能复用 `web/src/components/option-field.tsx`，颜色、图形、分区几何与选境共用；保留键盘方向键、Enter、焦点反馈、点击扩散和减少动态效果支持。规范也写入 `web/AGENTS.md`。

顶部悬浮栏始终显示进度：最多 10 步时每步一格，已完成与当前步骤分别标色；超过 10 步时固定 10 格，每完成 10% 点亮一格，同时显示整数百分比。问题使用实际已答题数，比较使用已完成轮数，任务选择象限显示写完任务后的 1/2；入口页按一次待选择的步骤显示。返回、重答同步更新进度，色块依旧铺满视口。

进度条可点击跳转至已到达的步骤，百分比格跳到对应区间起点（向上取整到实际步骤）。屏幕左右边缘中间的轻量箭头逐步返回、前进；首次尚未回答的步骤不能向前跳。浏览历史保留原答案和比较双方，不重复记录结果；修改答案后清除依赖旧答案的后续历史，选择相同答案则保留后续进度。原选境也支持相同的前进/返回行为。可用 `node scripts/check-option-navigation.cjs` 验证。

## 吃什么

`/eat` 展示「比较一下」与「问问自己」两项。

- 比较只使用 Tau 提供的 18 条初始记录，以及 Tau 手动添加的餐单。保留中英文名、代表菜、三级位置与标签，未确认地址不自动补写。每次选择保留胜者及其位置，替换被淘汰者；完整流程 N 个食物需要 N−1 次比较。「就吃这个」可随时提前决定。
- 问题库是独立的 116 条中英文食物和菜系，包含 24 个宽泛菜系，每个列三道中英文代表菜。8 道问题覆盖甜咸、辣味、饭面、汤汁、风味地区、清爽浓郁、肉类蔬食和便利程度。按标签加减分排序，持续显示前三项；不确定、都可以不改变排序，返回会撤销上一题的影响。问完后可选前三项，也可浏览搜索全部食物。
- 食物库是可扩展的灵感目录，不是声称穷尽所有食物的目录，也不实时查询餐厅菜单。料理标签描述常见做法；菜系代表菜不可用来推断所有菜品的配料。
- 决定后保存名称快照、中英文、时间、模式、是否提前决定及问题答案，保留最近 500 次。匿名使用保存在当前浏览器；登录后使用现有 SQLite 账号同步，账号之间分离。新增数据使用 `dining` 键，旧 `meals` 数据继续保留。
- 「只由 Tau 添加」对应本项目唯一的管理员角色。普通账号可以保存自己的选择记录，服务端拒绝普通账号写入自添餐单。初始 18 条不通过推荐算法扩充。

原饮食工具和营养记录从 `/eat/legacy` 访问；原博客欢迎页在 `/journal`，文章仍在 `/posts`。

饮食文化参考：[新加坡旅游局](https://www.visitsingapore.com/things-to-do/dining/)、[新加坡国家文物局：娘惹菜](https://www.roots.gov.sg/ich-landing/ich/peranakan-cuisine-in-singapore)、[国家文物局：叻沙](https://www.roots.gov.sg/ich-landing/ich/laksa)。餐厅名称和地址由 Tau 提供，按原文录入，并未宣称已核实当前营业或门店地址。

## 创建任务

首页「创建任务」打开 `/tasks/new`。填写任务名称和可选说明后，显示四个选境 options：重要紧急、重要不紧急、不重要紧急、不重要不紧急。点击后写入现有 `todos` 数据，可在待办四象限查看、编辑；不会创建独立且不互通的任务库。最多 200 条时会提示整理，避免静默丢弃。

## 验证

- `npm.cmd run build`：生产构建和 TypeScript 检查。
- `node scripts/check-food-options.cjs`：默认对本地 3037 预览运行，API 全部使用隔离数据；覆盖 1440×1000、390×844、360×640，完整淘汰、提前决定、刷新保留、问题回退、三候选、任务象限、管理员手添与模拟账号保存。截图在 `web/test-results/food-options/`。
- `TEST_ORIGIN` 可覆盖预览地址，只允许本机。
- `node scripts/check-dining-api.cjs`：仅对独立测试 API 的 5237 端口运行，须先设置独立 `Data__Directory`，管理员测试账号为 `options-test-tau`。验证新增餐单权限、选择记录往返、账号隔离、未登录访问和 CSRF。勿对日常数据目录运行。
- 原选境回归：`node scripts/check-choice-experience.cjs`。

本次未修改小程序。若本机后端正在运行，重启调试后才能加载新增的 `dining` 接口键。
