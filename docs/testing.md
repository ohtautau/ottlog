# 本次改动手动验收

按 README 的 VS 启动方式打开 http://localhost:3000，进入 /admin 登录。

以下保留此前博客阶段的检查清单和历史通过记录，原记录未注明执行日期，不表示当前全项目重新验收通过。当前开发验证入口见 [development.md](development.md)，小程序回归与原生验证边界见 [UI-PREVIEW.md](../miniprogram/scripts/UI-PREVIEW.md)，已知阻断见 [决策记录 T01](decisions.md)。后续新增验证结果应写明日期、命令与运行环境。

| 测试 | 操作 | 预期 |
| --- | --- | --- |
| 自动地址 | 新建文章，仅填标题、正文并保存 | 自动生成 post- 开头的地址，改标题后不变 |
| 自定义地址 | 勾选自定义地址，填英文短链接 | 保存后使用指定地址；重复地址提示冲突 |
| 空摘要 | 不填摘要，公开到博客 | 保存成功，列表有正文自动摘要 |
| 自动封面 | 保持自动选择，插入正文图片 | 封面预览切换为正文首张本地图片 |
| 自定义封面 | 点击上传自定义封面 | 自动模式关闭，预览变为上传图片 |
| 标签 | 点击已有标签，再点击一次 | 添加、移除成功，也可键入新标签 |
| 发布隔离 | 仅勾选微信小程序并保存 | 博客列表、详情、RSS 不展示该文章 |
| API 渠道 | 打开 /api/posts/地址?channel=mini | 小程序公开文章可见，默认不带参数是博客渠道 |
| 管理筛选 | 选择草稿、博客、小程序、分类 | 列表显示对应文章，支持组合搜索 |
| 排序 | 切换日期升降序与标题升序 | 列表顺序改变 |
| 分屏 | 输入标题、列表、代码块 | 代码和预览同时显示，手机上下排列 |
| 独立窗口 | 点击独立窗口、用快捷工具编辑 | 正文实时同步；关闭窗口后主页面保留正文 |
| 图片按钮 | 点击插入图片并选择 PNG | 上传完成后插入 Markdown，无原生未选择文件提示 |
| RSS | 点击页脚 RSS 订阅 | 进入说明页，复制正式订阅地址；原始文件保持 XML |
| 注册收藏 | 读者注册后收藏文章 | 收藏进入当前账号，刷新后仍在 |
| 跨设备 | 在另一个浏览器或小程序登录同一读者账号 | 同步收藏，各端仅显示该端公开文章 |
| 账号隔离 | 注册第二个读者账号 | 看不到第一个账号的收藏，不能调用管理 API |
| 管理入口 | 比较游客、读者、管理员登录后的菜单 | 管理入口仅管理员菜单显示；页脚没有后台链接 |
| 升级持久化 | 重启 API | 原文章、封面、发布状态、账号和收藏仍保留 |

读者与管理员共用 /account 登录入口，登录后按角色显示菜单；读者不能通过注册获取管理员权限。原本保存在本地设备的旧收藏不会自动关联新账号。

自动验证记录：28 项桌面/模拟手机及 API 测试全部通过；追加的图片按钮、自动/自定义封面切换、直接关闭独立窗口测试在桌面和手机均通过；旧数据库升级、首次建号、重启保留数据、密码撤销旧会话测试通过。后端、网页生产构建、网页 lint、小程序类型检查与编译通过。微信真机、正式服务器和真实域名尚未验收。

本次新增验收：

- 未登录或普通账号访问 /admin、/admin/comments，返回账号页面，不显示独立管理员登录表单。
- 现有管理员账号在 /account 登录成功后进入文章管理；普通账号不会获得管理菜单或 API 权限。
- 鼠标悬停 logo，所有字母及圆点高亮一致。
- 独立编辑窗口工具按钮样式一致，公式在编辑预览和公开正文中均正常渲染。
- 发布未选渠道时前后端均拒绝操作；保存草稿不要求渠道，并设为不公开。已发布文章保存为草稿将取消公开。
