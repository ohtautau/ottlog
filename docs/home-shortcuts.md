# 小程序主页快捷方式

P09 已于 2026-10-04 确认：首页快捷方式等个性设置随账号同步，游客使用本机设置并与账号隔离。当前仍是按设备保存，账号同步尚未实现。正式规则与状态见 [决策记录](decisions.md)，开发和设计约定见 [AGENTS.md](../AGENTS.md)、[Design.md](../Design.md)。

## 当前操作

「我的快捷方式」右侧的独立功能栏显示「排序／管理」，排序期间在同一位置显示「取消／保存」。快捷记录行在首页首屏内容最底部、翻页提示上方，仅显示输入框与右侧「＋」；输入后点击「＋」或键盘确认打开原统一创建弹窗。规则见 [C65／C66](../Design.md#首页底部快捷记录c66)。

- 只有点击「排序」后，才能直接在原来的主页上拖动排序；普通浏览时长按或滑动入口不会进入排序。双列卡片、下方小入口及各自的大小、颜色、文字和间距保持原样，大卡片与小入口分别调整顺序。连续拖动沿用本次已调整的顺序，长按不会重置为保存前的位置。拖到屏幕边缘会自动滚动，方便调整下方的快捷方式。顶部「取消／保存」文字按钮撤销或完成排序；排序期间不会打开功能。
- 点击「管理」，在功能列表中勾选或取消要显示的快捷方式，然后点击「保存快捷方式」。取消选择仅隐藏入口，不删除功能中的数据。
- 展开「名称与样式」，可修改显示名称（最多 8 个字，留空恢复原名）、颜色和显示样式。这里也保留「恢复默认布局」。
- 保存后立即应用并保存在本机，重新进入仍然有效。「取消」不保存本次修改；恢复默认也需要点击保存才生效。
- 支持隐藏所有入口，空主页仍有添加按钮。名称过长时主页显示省略号，编辑时显示完整名称。

下滑或点击「查看全部入口」后，全部功能在第二屏按「快捷操作／功能界面」分组。操作包括创建任务、创建便签、开始番茄钟；界面包括便签列表、数据和番茄钟等。「开始番茄钟」立即开始／继续计时，「番茄钟」只打开页面，暂停的计时不会自动继续。规则见 [C68](../Design.md#全部功能的操作与界面c68)。

不再单独显示「更多快捷方式」分区，首屏未显示的快捷方式合并到目录同一目的地：默认查看任务和读点什么显示为「待办／文章」，自定义名称和图标颜色保留，同组按保存顺序优先排列。首屏原卡片、小入口及偏好保存规则保留，目录中的溢出项仍可参与排序；同目的地别名只显示一个，原设置记录不删除。最近打开仍在目录之后，隐藏所有个性快捷方式也不会隐藏完整目录。

「我的快捷方式」和目录两组按 [C67](../Design.md#通用小标题c67) 使用同一 `SectionTitle`，统一为 14px／600、行高 1.4、灰蓝色，无额外字距；宽屏大小相同。「全部功能」作为翻页分区主标题保留原层级。

「统计」仍可在管理面板选为快捷方式；「我的」工具区同样可打开统计。它通过普通页面导航进入独立分包，底部五个导航入口保持现状。首页按 C48 只保留快捷入口和全部入口两屏；「领域进展」快捷方式直接进入领域主界面，再点击领域卡片进入详情。领域目标和习惯口径见 [首页与领域入口](miniprogram.md#首页两屏与领域入口c48)，旧成长记录与图表继续在统计的成长分类查看。

「领域进展」沿用原快捷方式键 `growth`，不改变已保存的入口顺序、颜色或大小；旧默认名称「成长足迹」读取时迁移为新默认名，其他自定义名称保留。该键按 C48 负责通过 tabBar 打开领域主界面，不能据此读取或修改同名工具存档。

按 C23，「领域进展」标题下显示「每一步，都有进展」和英文装饰「ONE STEP AT A TIME」，沿用同类大卡片的文字层级、间距与透明度。文案由共享快捷方式目录提供，已有快捷方式无需重置；改成小入口时使用现有小入口样式显示中文说明，用户自定义名称仍保留。后续功能改名时不能意外清空配套装饰文字。

2026-10-05 C23 验证：`typecheck`、`test:home-shortcuts` 和 `build:weapp` 通过；浏览器适配预览覆盖 360、375、430、768 像素宽度，375 与 768 像素截图已目检，装饰文字正常显示且层级一致。主包 1,391,867 字节，启动和原包体预算检查通过；未进行微信开发者工具或真机验证。

本机存储键为 `ottlog.home-shortcuts.v1`，版本为 1。首次进入沿用六张大卡片和两个小入口；当前布局按设备保存，不随账号同步，也未按账号分别存储。自定义功能使用固定入口目录，不接受外部链接。存储失败会保留编辑内容并提示重试。

## 创建快捷方式与控件样式（C39）

首页「创建任务」「创建便签」快捷方式直接显示名称，名称旁不加小加号；卡片、小链接、全部功能及最近入口均遵循。保留原功能图标、装饰文字、自定义名称、颜色和大小，不机械改为普通按钮；该规则替代 C37 初版给创建快捷方式名称加号的要求。首页单行输入右侧按 C65 使用 `CreateButton iconOnly`，仅显示「＋」；其他功能栏紧凑创建入口继续使用加号和完整动作名称。

排序、编辑、保存及分类选项复用 [C39 共用控件外观](../Design.md#按钮与分类控件外观c39)，工具栏用紧凑 14px／40px，正式保存提交 16px／48px，选中前后不改变字体和几何。原排序图标与无障碍名称保留；严格像素／几何回归仍须通过，不能把更改按钮字号当作取消原卡片布局标准的理由。

## 已确认的后续规则

- 账号同步（P09）待实现：登录后的入口顺序、显示名称、颜色、大小样式及显示范围属于个性设置，随账号同步；游客仍使用本机设置，游客设置不自动并入账号。应复用共享状态层和账号保存队列，不在页面增加独立同步实现。
- 编辑草稿（P08）待统一实现：关闭未保存的修改保留本机草稿，下次继续；草稿按账号及编辑对象隔离。草稿不代表正式布局已保存，取消或关闭不能产生业务记录；当前修改面板仍按上方操作说明丢弃未保存修改。
- 多设备自动合并（P10）已确认方向，尚待实现；同一设置的编辑冲突等细节仍需定义，不擅自规定“最后一次保存”作为冲突规则。
- 小屏可读和操作易点优先（P03）；内部滚动条默认隐藏并提供明确滚动提示（P04）。不要为维持固定首屏数量压缩文字或按钮。普通开发范围只涉及小程序（P01）。

习惯拖动后自动进入自定义排序的 P02 只规定习惯排序，不能据此把当前快捷方式的「保存／取消」操作改为自动保存。

功能图标沿用已有素材，不依赖系统字体或 emoji；数据复用原统计柱图。大卡片为 64rpx，小快捷入口为 36rpx，全部功能按 C52 固定 20px，编辑选择面板为 44rpx；同一套图形保留原有配色。图形源定义在 `miniprogram/scripts/generate-shortcut-icons.cjs`，在项目根目录运行 `node miniprogram/scripts/generate-shortcut-icons.cjs` 可重新生成素材（使用 web 的 sharp 依赖）。

运行 `npm.cmd run test:home-shortcuts` 检查排序前后卡片截图一致、原有布局与样式保持、连续拖动及长按不跳位、普通浏览禁止拖动、边缘自动滚动、触摸取消、功能勾选、名称颜色与样式修改、保存后刷新、取消与恢复默认、存储失败和入口导航。浏览器适配检查覆盖 360、375×667、430 和 768 宽度；微信原生长按、触摸和 Picker 仍需在开发者工具或真机体验。账号同步及草稿实现后补充持久化、账号隔离、设备间恢复和冲突场景验证，不能以现有本机布局检查通过代替新功能验收。原生交互改动和发布前按 P11 补充微信环境验证。
