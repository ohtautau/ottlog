# 小程序任务与四象限

首页点「创建任务」直接打开表单；点「查看任务」或底部「待办」进入四象限。

- 左上：高优先级，红色，重要且紧急。
- 右上：中优先级，黄色，重要不紧急。
- 左下：低优先级，蓝色，紧急但不重要。
- 右下：无优先级，绿色，不重要不紧急。

普通创建按 [C47](../Design.md#新建默认优先度c47) 默认无优先度；点击各象限右上角的「＋」打开同一创建弹窗，初始优先度对应所在象限（[C56](../Design.md#四象限创建入口c56)）。每个象限保留一个加号入口，原底部创建栏已移除。任务名称必填，日期和时间、备注、标签默认均为空。可以只选日期而不选具体时间。

四个框以 2×2 等分布局铺满首屏核心区域，四区同时可见，任务列表分别在框内滚动。每个象限先列未完成任务，下方默认显示灰色的已完成任务，可按象限一次收起。左侧勾选完成，点击任务名称编辑。顶部「筛选」打开关键词与标签面板，显示匹配数量；条件同时生效，可一键清除。下滑进入同步区域，数据分析在独立「统计」功能查看。

顶部功能栏与导航栏之间保留 12px 留白（[C57](../Design.md#四象限顶部留白c57)），四象限在剩余首屏空间内完整显示；下页返回和页面往返后也保持该间距。

筛选面板底部按 C33 显示左侧「查看 N 件任务」、右侧「清除筛选」；查看保留主要按钮样式及较大宽度。查看关闭面板并展示当前筛选结果，清除重置关键词、标签和完成状态。相同的查看／清除组合沿用此顺序，设计规则见 [Design.md](../Design.md#表单与滚动)。

拖动任务右侧把手可调整象限内顺序或移到其他象限，跨象限更新优先级。长列表支持边缘自动滚动，取消拖动不保存。手动顺序保存在任务数组中；「按时间」按日期及时间升序排列，无日期在最后，同日未指定时间按当天末尾处理。在时间排序中拖动会以当前可见顺序为基础切换为手动排序。

列表标题最多显示两行，点击可查看或编辑完整内容。日期区分今天和逾期，跨年日期保留年份；循环及后续步骤显示为简短摘要。标签显示前两个及剩余数量，完整标签仍保存在任务中。象限标题前显示简易旗帜图标，不显示待完成数量。

创建与编辑表单遵循 [C28 共用规范](../Design.md#实体创建与编辑c28)：日程在标题上方，标题左为图标、最右为优先度；「准备做什么？」输入框下直接显示备注，备注不再折叠。优先度按钮不显示上下箭头，点击打开相邻的 136px 独立窄浮窗，以对应颜色的旗帜图标＋「高优先度／中优先度／低优先度／无优先度」四项竖排，减少右侧留白，选择后收起（C40／C59）。

任务备注支持 Markdown 书写／预览和图片插入、查看、移除，复用备忘录正文编辑区（[C44](../Design.md#任务备注与备忘录正文c44)）。图片会随原任务保存，重开编辑继续保留；每件任务最多 6 张，沿用压缩与空间限制。工具栏和图片位于备注内，完整备注编辑区下方才是下一步。

备注下方以分隔线区分默认显示的下一步输入行，每行左侧使用圆点子弹头（C40），直接在类似标题的文本框里输入，提示为「还要做什么？」（C31）；无需先点「＋」录入第一步。「＋」用于追加更多步骤，标签位于下一步之后。默认空白首行仅作输入占位，不创建空后续任务，也不阻止只保存当前任务。

常用标签按 [C46](../Design.md#标签行宽度分配c46) 等宽分配可用空间并尽量铺满一行，行末紧邻的上下 chevron 打开悬浮多选窗，可选择已有标签并从末尾输入自定义标签；前排与浮窗共享选中值。同账号任务与备忘录合并标签频次（C34），默认标签保留工作、学习、生活、购物，旧分类按名称合并为标签，兼容数据结构保留。检查步骤入口已移除，旧数据保留。任务表单已使用共享字段组件实现 C28，验证按实际运行结果记录。

「统计」中的待办分类沿用近 7 天、近 30 天每日完成柱状图与当前优先级条形图，点击图形查看任务明细。完成数量按所选期间计算；待办与逾期是当前快照，已删除记录不计入。任务页专注操作、当前状态与记录编辑，统计入口和数据边界见 [统计说明](statistics-miniprogram.md)。

## 任务与备忘录共用创建（C34）

新建流程以任务表单为基准共用一个弹窗：在首页原生单行输入中填写内容，点右侧「创建」就地展开；创建快捷入口打开同一弹窗，弹窗内可一键切换任务／备忘录。共享组件与本机草稿已实现，规则见 [C34](../Design.md#任务与备忘录共用创建c34)，实际验证范围见 [开发说明](development.md#任务与备忘录共用创建c34)。

切换保留标题、Markdown 备注／正文、图片、标签和优先度，任务日程与下一步、备忘录颜色／置顶／图标等专属内容独立保留，切回可继续；只保存当前类型。编辑既有任务或备忘录仍更新原类型和原 ID，不能用切换创建另一种实体来替代编辑。标签按同账号任务与备忘录记录合并频次，兼容旧分类，保留默认与自定义标签。

普通新建任务与备忘录按 C47 默认无优先度，象限新增任务沿用该象限；手动选择、类型切换、草稿恢复及编辑已有记录保留当前值。历史未记录优先度的备忘录按无显示。切换不截断输入，保存任务时校验标题 100 字／备注 10000 字，保存备忘录时校验标题 80 字／正文 6000 字，超限保留内容并提示修改。创建草稿按账号存本机，关闭后重开恢复，游客隔离；存储键及实际完成范围见 [开发说明](development.md#任务与备忘录共用创建c34)，不能视为所有编辑器的 P08 已实现。语音输入使用输入法自带语音转文字。

打开时按入口指定的类型恢复内容；已有草稿标题非空且与首页新输入不同时保留旧标题，新输入追加到备注／正文并提示。相同首页输入关闭后重开不重复追加，也不覆盖在弹窗内改过的标题。若本机保存失败，界面和草稿保留，以同一记录重试，保存成功后才清理草稿，避免重复创建。

## 日期、提醒与重复

创建和编辑任务在标题上方点击日程按钮打开同一个设置面板；未设置时仅显示「日期」，已有日期、提醒或重复时显示简短摘要，重新打开可继续修改。

默认日历和时间／提醒／重复三行可完整显示，无需滚动；「确认／清除」固定在面板底部，保留底部安全区。年月、时间、提醒和重复按 [C41](../Design.md#独立选项窗口c41) 打开应用内独立小窗，主日历与三行位置保持；必要时仅小窗中部滚动，标题与操作常驻。

月份左右切换与回到今天这类无边框按钮，鼠标悬停显示浅半透明底，移开恢复透明；触摸按下保留同样反馈，禁用月份边界按钮不高亮（[C43](../Design.md#无边框按钮反馈c43)）。

年月、时间、提醒时间和重复间隔按 [C42](../Design.md#单行数字输入对齐c42) 共用数字输入，默认与编辑后均在框内垂直居中，数字与单位对齐；点击整个框可输入。

底部间距按 [C29](../Design.md#弹层底部操作c29) 由共享 `SheetActions` 管理：待办页已有原生导航，不再为按钮栏重复预留整机安全区；按钮到底部留 8px。“重复”末行与按钮栏之间只显示一条分隔线，默认完整日历与固定按钮仍保留。

- 日历显示当前月份，可切换上一月、下一月、回到今天，点击月份可跳转年月，也可直接选择今天、明天、下周或无日期。「下周」选择今天往后七天的同一星期，例如周日选择下周日，支持跨月、跨年。日历日期和快捷按钮以浅绿色底色表示当前选择；手动选日与快捷选择同步，重开根据草稿恢复高亮。选择提醒日期时，高亮跟随提醒日期。
- 「时间」点击打开独立小窗，通过小时和分钟输入设置；可以仅保留日期，不指定时间。
- 「提醒」点击打开独立小窗设置提醒日期和时间，提醒日期另开完整日历小窗且不替换任务主日历；选择提醒时间不等于已获得微信订阅授权。
- 「重复」点击打开独立小窗，直接选择不重复、每天、每周、每月、每年、工作日或自定义间隔；生成后续任务的规则沿用下文的循环机制。

面板修改先保留在自身草稿中，点击「确认」回填任务表单；最终保存任务才写入正式记录。关闭或取消面板不回填，也不创建任务。「清除」先清空面板内的日期、时间、提醒和重复，点击「确认」后才回填，保留任务名称、优先度、标签、备注与下一步等其他字段。

任务继续沿用 `dueDate`、`dueTime`、`reminderAt` 和 `recurrence`，已有任务及旧存档可继续编辑。改变提醒时间后取消旧提醒等处理沿用下文规则。

## 循环与下一步

循环支持每天、每周、每月、每年、工作日及自定义间隔；工作日指周一至周五，不额外计算节假日。完成当前任务时生成下一周期的一件任务；有任务日期时从原日期推进一个周期，无日期时从完成当天计算。逾期任务不会跳过中间周期。每月遇到不存在的日期会落到月底，并尽可能保留原日号，例如 1 月 31 日 → 2 月 28 日 → 3 月 31 日。

「下一步任务」可以连续添加、调整顺序和删除步骤，编辑时保留已有任务链。完成 A 后生成 B，B 携带剩余的 C、D；完成 B 才生成 C。后续任务继承优先级、标签和备注（含图片），但不继承旧日期、循环规则或微信提醒。

同一任务同时设定循环和下一步时，完成会生成下一周期任务以及任务链的第一步各一件。下一周期副本不复制旧任务链。取消完成再勾选不会重复生成已经创建的后续任务，也不会删除已经生成的任务。

旧的「任务内检查步骤」继续保留，它们只属于当前任务，勾选不会生成独立任务。最多保存 200 件任务；当容量不足以生成后续任务时，操作会提示清理，原任务不会被部分完成。

## 微信提醒

先在日程面板的「提醒」中选择日期和时间，确认并保存任务，再打开日程面板的「提醒」，点击「开启微信提醒」授权。需要登录已有 Ottlog 账号，并完成任务同步；服务端通过微信登录 code 绑定当前微信身份。仅选择提醒时间或保存任务不等于订阅成功，必要的微信平台授权仍保留。

模板和凭据尚未配置时，页面保留时间设置并提示未开通。开通步骤见 [微信提醒配置](wechat-reminders.md)。每个新生成的任务需要重新设置提醒并获得订阅；不能把一次性授权当作永久循环提醒。

完成、删除任务或改变通知时间会取消旧提醒；离线修改需等同步到服务器后才生效，不能保证已在云端安排的提醒立即停止。发送结果未确认时不自动重试，避免重复通知。

## 验证范围

任务逻辑测试涵盖旧数据、周期/月底、任务链、重复完成和容量边界。浏览器适配预览检查四种屏幕宽度（含 375×667 短屏）、表单、象限及任务完成流程；C28 表单应检查单选浮窗、标签多选与自定义、备注常显、字段顺序及展开方向，保存和重开保留原值。日程面板应检查默认无需滚动、年月／时间／提醒／重复使用独立窗口、主日历位置稳定、提醒日历完整及子窗逐层关闭保留草稿、设置行不被底部按钮遮挡、月份切换、快捷日期、时间／提醒／重复、确认、取消、清除以及保存后重开。后端验证使用临时数据库和模拟微信接口。真实微信布局、安全区、授权与到达效果仍需在微信开发者工具和真机上验收。

C34 增加统一创建入口、双向切换保留、按当前类型保存与校验、草稿关闭恢复、原 ID 编辑、共享标签、旧备忘录优先度、异步失败及账号切换的隔离检查。本轮类型、全部纯逻辑、统一创建与最终任务／备忘录／首页快捷／布局／翻页及 34px 模拟安全区四尺寸浏览器套件和最终构建已通过。长标题／正文、144 字原始标签及首页重复输入按四尺寸验证；账号切换、本机写失败的同 ID 重试仅一条记录、坏草稿分支仅在 360px 执行，详见开发说明。微信环境、键盘及输入法语音仍未实测；本轮未一次执行全部 `verify`。
