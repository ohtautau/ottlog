# 待办、番茄钟与备忘录

右上角「导航」抽屉提供入口，悬停或点击展开，鼠标离开后收起；支持键盘和触屏。五个工具支持宽屏工作区，共用同一套导航：开饭指南、习惯养成、待办清单、番茄钟、备忘录，当前页面高亮显示。

各工具支持 JSON 导入导出，入口位于页面顶部。支持预览、合并、确认替换，详见 [数据备份说明](tool-backups.md)。

首页格言轮播栏旁的「＋ 添加格言」仅管理员可见，默认收起；点击后展开紧凑输入框，按 Enter 或点击「添加格言」直接保存到自定义格言库，立即更新首页随机轮播。每句最多 120 个字符，共 50 句，拒绝重复；可在后台「首页格言」逐句管理。此入口不写入备忘录。

## 开饭指南与习惯养成

- 开饭有双菜卡二选一与问答卡两种模式，均可左/右/上滑；方向提示同时是按钮，键盘也可选择。
- 「餐单与饮食记录」中用一份备份管理菜品库及碳水、蛋白质、脂肪记录。
- 习惯卡片带主题图标、静态背景与分组颜色；周圆圈显示星期和日期，可以补记或撤销。
- 编辑习惯时可从 30 款插画中选择，查看动效、下载静态 SVG，或上传自己的图片/使用 HTTPS 图片地址。

## 待办清单

- 重要/紧急两个属性组成四象限，可切换列表、日历与统计。
- 四象限优先展示，每个象限内部滚动；搜索、筛选、排序和分类管理收在默认折叠的「整理我的待办」中。折叠保留条件，摘要提示当前筛选结果。
- 创建与编辑标题、Markdown 详情、分类、截止日期；点击任务查看详情，支持子任务和子任务拖动排序。
- 拖动手柄调整任务顺序或移动到其他象限，支持触屏；完成后可重新打开，删除后可撤销。
- 分类可新建、改名、配色、删除；删除分类会保留待办，并移入未分类。
- 搜索标题、说明与分类，组合分类、状态、象限、日期筛选，按优先级、截止日期、新旧或标题排序。
- 日历按截止日期查看事项，统计提供完成、逾期、完成率、七天趋势与分类分布。
- 待办上的专注入口将事项传给番茄钟；历史记录可返回原待办。支持已完成事项的链接定位。
- 初始没有虚构待办。最多 200 件待办、30 个分类，标题 100 字、Markdown 说明 10,000 字。

## 番茄钟

- 默认专注 25 分钟、短休息 5 分钟、长休息 15 分钟，每 4 轮专注后安排长休息；可自行调整。
- 可以关联待办，或填写独立事件名称；记录保留当时的事项名称，原待办删除后历史仍可读。
- 支持开始、暂停、继续、提前结束并记录、重置本轮。重置不写入统计。
- 刷新或离开后回来会恢复计时；后台结束按原截止时间记账，暂停时长不计入专注。
- 完成后需要手动开启下一轮，避免无人使用时连续产生记录。同一轮 ID 只记录一次。
- 今日、近七天、累计时长、完成轮数、七天柱状图、月历与日期历史；专注和休息分开统计。
- 提前结束只计入实际时长，不算完整番茄。跨日记录归入结束当天。
- 保留最近 1,000 条计时记录，可逐条删除；统计基于保留的记录。

## 备忘录

- 进入页面即可编辑空白纸页，恢复已有草稿；手机先显示编辑器，颜色与标签设置可折叠。
- 新增、编辑、搜索、颜色与标签、置顶、排序、删除与撤销。
- Markdown 工具栏、编辑/对照/预览视图，支持公式；不执行原始 HTML。
- 保存按钮和 Ctrl/⌘+S；切换备忘时自动提交保存。
- 键入时只更新按账号分区的本机草稿，刷新或导航回来可恢复。只有保存后的内容同步到其他设备。
- 若其他页面已更新同一条备忘，保留当前草稿，并提供另存一份或读取最新版本。
- 最多 50 条备忘，每条标题 80 字、正文 6,000 字、5 个标签。

## 保存与运行

游客数据保存在当前浏览器，登录后使用该账号自己的数据；游客数据不自动并入账号。

共用 `PersonalToolStates` 表，新增存储键 `todos`、`pomodoro`、`memos`，无需新增迁移或重置数据库。每个新工具内容上限 1 MB；习惯养成（含自定义背景）为 1 MB，餐单保持 128 KB 上限。接口继续要求登录及写入 CSRF 校验，按管理员/读者和账号 ID 隔离。

同一浏览器的页面间同步本地修改；支持浏览器写锁时串行上传，延迟读取和旧页面操作不会回滚较新的本地记录。连接异常会提示暂存及重试。

Visual Studio 若仍运行旧版 API，停止调试后重新 F5 即可加载新接口。测试服务使用随机空闲端口及独立数据库，不占用 3000/5229。

## 验证

在项目根目录：

```powershell
dotnet build backend/Ottlog.Api/Ottlog.Api.csproj -c PersonalTools
.tools/python/python.exe scripts/personal-tools-test.py
.tools/python/python.exe scripts/productivity-preview.py --check
```

临时服务结束时自动停止自己启动的进程。截图、日志与测试数据库留在忽略目录 `web/test-results`。

在 `web` 目录：

```powershell
node --test src/app/pomodoro/pomodoro-data.test.mjs
npm.cmd run build
```

验收包括任务分类与四视图、计时与待办关联、暂停/刷新/提前结束/重置、草稿恢复、公式、删除撤销、账号隔离、多标签页延迟请求，以及 320/390/768/1440 宽度和减弱动画模式。
