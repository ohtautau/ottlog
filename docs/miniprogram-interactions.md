# 小程序习惯推荐、选境和专注分析

## 习惯

当前组件与交互规则见 [Design.md](../Design.md)，2026-10-04 已确认规则和实现状态见 [决策记录](decisions.md)。后续功能开发范围只修改小程序。

当前首屏展示按领域筛选的双列习惯网格，默认先按优先度高、中、低、无，再按创建时间新到旧；另有最多两个待打卡习惯建议，排除当天完成和暂停项。各处卡片优先度统一为右上角色标。习惯页主网格与领域详情直接复用 `HabitCard` 和 `reminders` 数据；页面只负责排列和滚动，卡片基础样式与行为统一在共享组件修改，不需要用户再次确认两处是否一致。

P02 已确认：一旦拖动确实改变顺序，自动切换为自定义排序并持久保存；离开后再回来恢复已保存顺序，默认优先度和创建日期排序不能覆盖它。不是要求用户预先手动选模式。当前代码仍需点击保存，且展示会重新应用自动排序，完整自定义模式与恢复待实现；新增习惯的插入位置等细节尚待规定。

P03、P04 已确认：文字可读和操作易点优先，小屏可减少首屏可见卡片并滚动；内部滚动条默认隐藏，并提供清楚的滚动或分页提示。当前习惯主网格仍显示滚动条，领域详情的 2×2 横向列表已隐藏滚动条，统一提示与隐藏规则仍待落实。

P05 已确认未分类为不能改名或删除、不占自建名额的系统领域，目前仍是按需创建的普通领域，尚待实现。P06 已确认删除普通领域保留共享习惯并转为未分类；不能删除 `reminders` 中的习惯或打卡记录，领域删除确认的旧文案待修正。

旧的时段推荐逻辑和本机打开日志仍保留在代码中，不能把它当作当前首屏展示规则。主动打开详情才记录打开时间，与打卡日期分开；打开日志按本机账号隔离，不改变云端打卡数据。

创建习惯与任务编辑器按 [C28](../Design.md#实体创建与编辑c28) 使用一致的字段层级和悬浮选择：标题左为图标、最右为优先度，备注在标题下常显；领域等单选使用单按钮打开选项窗，保留「高／中／低／无」优先度。专注分钟常用在前、创建默认最常用、末尾提供自定义输入，编辑保留已有值。习惯页与领域详情复用同一 `HabitEditor` 和 `form-options.tsx`；展开／收起统一复用旋转上下 chevron。

首屏卡片提供查看和打卡，全部习惯、七日补记及管理位于下滑区域。综合分析和日汇总在独立「统计」查看（C18）；习惯卡保留闪电累计与火花连续天数（C21），点击卡片按 C27 恢复单习惯月统计、42 格月历、月份切换及月日志，日期格只读。原习惯页保留打卡、撤销、补记与编辑。P08 已确认关闭编辑器应保留按账号及编辑对象隔离的本机草稿，下次继续，保存前不产生正式记录；当前编辑器尚未统一实现草稿恢复。

习惯详情按 [C32](../Design.md#默认视图完整性c32) 共用 `HabitCalendar layout='detail'`，面板 `height: min(620PX,100%)`、`max-height: 100%`，随实际可用视口限制高度；默认完整显示四项统计、42 格月份日历、图例及日志／专注按钮，底部完成／编辑不能遮住最后一周。日期只读行至少 30px，按钮至少 40px。月日志提供可展开入口，与专注同行；超过 32 字的标题共用 `HabitDetailTitle`，默认最多两行并以旋转箭头展开全文。短备注直接显示，超过 48 字或多行的备注共用 `HabitDetailNote` 从「提醒自己的话」展开；标题和备注原文保留，编辑表单备注框始终常显。日志及展开内容可明确滚动，统计页保留原模式；默认验收须联合检查长标题、长备注和专注，并核对日历面板、末格、图例及入口的实际可见位置。

30 个彩色图标的源文件位于 `web/public/habit-icons/`，采用统一的 48 × 48 透明画布和具体物体造型。网页直接使用 SVG；运行 `node miniprogram/scripts/generate-habit-icons.cjs --preview` 生成小程序使用的 192 × 192 透明 PNG，同时输出大小图标对照图到 `miniprogram/test-results/habit-icons-colour.png`。这是现有共享素材流程，P01 不授权修改网页功能；仅修改小程序图标时先核对素材来源和生成范围，避免意外更改网页素材。

## 选境

四选项采用 X 分区，五选项使用中心菱形，六至九项采用对称折线。`choice-aligned-geometry.ts` 同时提供背景生成与触摸命中坐标，避免不同设备的多边形裁切差异；选项文字保持原生按钮，背景 PNG 由 `generate-choice-layouts.cjs` 生成。

## 专注分析

专注分析集中在独立「统计」的专注分类，入口及数据边界见 [统计说明](statistics-miniprogram.md)。近 7 天或 30 天的专注时长按结束日期归属。柱状图展示每日时长，横向条形图展示投入最多的六个事项，点击可查看明细。休息和未结束的当前计时不计入，提前结束按实际时长计入。指标包括总分钟、完整番茄数量和每轮平均分钟；发现根据当前保留记录生成。原番茄钟页保留计时、轮次、历史筛选与删除，原今日汇总和七日投入图也迁至统计。

## 验证

在 `miniprogram` 目录运行 `npm.cmd run test:improvements`、`npm.cmd run test:daily`、`npm.cmd run test:choose` 检查四种屏幕尺寸的相关交互。纯逻辑回归包含在 `npm.cmd run test:logic`；按范围运行类型检查与构建。自定义排序实现后应验证实际拖动、未改变顺序的手势、持久保存、切换页面后恢复，以及账号隔离和自动排序不覆盖自定义顺序。浏览器适配预览不替代微信原生触摸和渲染验收；原生交互改动及发布前按 P11 补充微信环境验证，报告实际执行结果。
