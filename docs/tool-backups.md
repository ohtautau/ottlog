# 日常工具数据备份

五个工具页顶部都有「数据导入 / 导出」入口。每个工具单独导出 JSON 备份，支持在其他浏览器、设备或账号中导入。

## 使用

1. 打开工具，点击「数据导入 / 导出」。
2. 点击「导出 JSON」，下载当前工具的已保存数据。备忘录需先保存正在编辑的草稿。
3. 在目标工具点击「选择 JSON 文件」，预览文件名称、导出时间、数量和导入后的概况。
4. 默认合并：保留当前记录，新增备份中不同编号的记录。重复导入同一文件不会重复新增。
5. 如需替换，选择「替换当前数据」并勾选确认，再点击「确认导入」。仅影响当前工具；可先用导出按钮备份现有内容。

游客保存到当前浏览器；登录后导入到当前账号，并沿用自动同步。游客数据迁移到账号时，可先以游客身份导出，再登录并导入。

## 保存范围与合并规则

| 工具 | 保存内容 | 合并行为 |
| --- | --- | --- |
| 开饭指南 | 餐食、店铺、口味、预算、准备时间、时段及每日碳水/蛋白质/脂肪记录 | 相同编号保留当前餐食 |
| 习惯养成 | 习惯内容、分组、场景、自定义背景、启用状态、星期完成记录 | 相同编号保留当前行动，同一天完成记录取并集 |
| 待办清单 | 待办、Markdown 详情、子任务及排序、分类、重要/紧急、截止日期、完成状态 | 同名分类复用当前分类，导入待办相应调整分类关联 |
| 番茄钟 | 设置、历史记录、关联事项、当前未结束计时 | 合并只新增历史，保留当前设置和计时 |
| 备忘录 | 已保存正文、Markdown、标签、颜色、置顶、时间 | 相同编号保留当前备忘；本机未保存草稿不包含在备份中 |

番茄钟导出时生成暂停快照，页面中的计时继续进行。替换导入后，未结束计时停留在导出时的进度，需要手动继续；当前工具已有未结束计时，则先结束或重置后才可替换。先导入待办备份，再导入番茄钟，可恢复原有待办关联；缺少原待办时，计时记录仍保留事项名称。

备忘存在未保存草稿时，会要求先保存或移除草稿。替换预览期间若当前数据有更新，确认操作会中止，可以重新核对并再次确认。合并会基于提交时的最新本地记录执行。

## 文件与容量

备份文件最大 8 MB，使用带格式标识、版本号、工具类型、导出时间和数据的 JSON。文件内容示例：

```json
{
  "format": "ottlog-personal-tool",
  "version": 1,
  "tool": "memos",
  "exportedAt": "2026-09-09T08:00:00.000Z",
  "data": { "version": 1, "notes": [] }
}
```

导入后的容量沿用现有工具上限：餐食 150 道；行动 80 条及 90 天完成记录；待办 200 件、分类 30 个；番茄钟历史 1,000 条；备忘 50 条、每条正文 6,000 字。餐食数据不超过 128 KB；习惯（含自定义背景）及其他工具各不超过 1 MB。

错误工具、错误版本、非法记录、重复编号和超限数据会被拒绝，不会截断记录或部分写入。备份不包含登录凭据。

## 验证

在 `web` 目录运行 `node scripts/check-tool-backup-model.cjs` 验证格式、合并、容量及计时快照。启动隔离预览后，运行 `node scripts/check-tool-backups.cjs` 验证真实下载、五种工具导入、草稿保护、重复导入、过期预览、无 Web Locks 的降级处理、手机弹窗及账号同步。
