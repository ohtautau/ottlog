# 小程序统计

2026-10-05 按 [C18](decisions.md#已确认) 将既有分析和汇总集中为独立「统计」功能；同日 C20 移除首页成长录入、C48 移除后续首页领域概览，领域主列表按 C38 保留进展摘要，2026-10-06 的 C50 改为两列领域卡并暂不展示目标内容，C21 明确习惯卡保留闪电累计天数和火花连续天数，C27 恢复单习惯详情的共享月历与月统计。开发规则见 [AGENTS.md](../AGENTS.md)，布局与交互见 [Design.md](../Design.md)。调整只涉及小程序。

## 入口与分类

首页全部功能的「功能界面」组中「数据」和「我的」工具区都可打开统计，也可在首页管理快捷方式时选中「统计」。首页目录按 [C68](../Design.md#全部功能的操作与界面c68) 区分操作与界面，页面地址仍为 `pages/statistics/index`，使用独立分包和普通页面导航，页内返回沿用共享「返回」按钮。底部仍为今日、待办、领域、习惯、我的五个入口。

统计分为待办、专注、习惯、饮食、领域、成长六类，分类与期间通过页内按钮选择。各类引用自己的原始工具数据，沿用既有计算口径。

内容分组和图表小标题按 [C67](../Design.md#通用小标题c67) 复用 `SectionTitle`；「今日完成」「习惯记录」「每日营养」「累计完成目标」等统一为 14px／600、行高 1.4、灰蓝色，宽屏不放大。指标数字、单位、领域名称与分类按钮保留各自含义及样式，不改变原统计数据。

| 分类 | 数据来源 | 迁入的既有分析与汇总 |
| --- | --- | --- |
| 待办 | `todos` | 期间完成数、当前待办与逾期、每日完成趋势及当前优先度分布 |
| 专注 | `pomodoro` | 期间专注分钟、完整轮数、每轮平均分钟、每日投入、事项投入及原今日／七日汇总 |
| 习惯 | `reminders` | 今日完成与进度，以及选择习惯后的累计、连续天数和月历完成率 |
| 饮食 | `meals` | 每日碳水、蛋白质及脂肪合计 |
| 领域 | `domains` | 各领域累计完成目标数及已完成目标历史 |
| 成长 | `growth` | 累计及本周成长值、已完成目标、各成长领域近三个月／本月／本周的值与图表 |

领域与成长使用不同存档，各自汇总；同名领域不代表同一条业务记录。

| 原入口 | 保留的操作与内容 |

首页按 C48 保留快捷入口和全部入口两屏，领域进展及旧汇总／最近活动屏、小／中／大进步录入均移除。领域主列表继续只读引用 `domains` 和 `reminders`，口径见 [首页与领域入口](miniprogram.md#首页两屏与领域入口c48)。原 `growth` 数据保留并在统计的成长分类查看；首页不再提供成长录入、目标管理或归档，不将旧成长值转换为领域目标或习惯完成数。

C22 的三条独立进展线已由 C38 的单线分段替代，首页概览进一步由 C48 移除；领域主列表仍使用长期／短期／习惯的 6／3／1 示意单位，原读取来源与计算口径保留。

## 数据与账号

统计通过共享 `usePersonalToolState` 读取原工具数据，不新增统计工具键、缓存副本或单独同步队列。统计界面不主动写业务数据；共享状态层原有的缓存读取、待同步保存和同步重试继续工作。

多源读取就绪且 `owner` 一致后才能展示，当前选择类别的存档还应通过已有格式校验。读取期间显示状态；失败、不兼容或账号尚未一致时保留提示和重试入口，避免把错误或不同账号的数据当作空记录显示。切换账号或登录／退出后重新读取，游客数据不自动合并进账号。

游客使用本机记录；已登录账号沿用该账号的本机缓存与同步状态，离线时只能使用已确认身份的本机数据。数据更新及返回统计页后重新读取仍由共享状态层负责。P10 的跨设备逐条合并尚未实现，本次统计展示迁移不改变这一限制。

## 计算口径与留存

- 待办和专注沿用近 7 天／近 30 天分析。待办完成趋势按完成日期归属；待办与逾期是当前快照，不随期间切换。任务最多保留 200 件，已删除任务不计入。
- 专注按结束日期归属；休息与未结束的计时不计入，提前结束按实际投入计入。仅基于保留的最近 1,000 条计时记录计算，累计完整轮数仍独立用于长休息节奏。
- 习惯日期明细保留最近 90 个记录日；累计字段和近期明细各沿用原有口径，不能把有限明细标为完整历史。
- 饮食每日合计来自当天保留的每餐记录，原页仍可编辑原记录。领域与成长按各自工具中的目标历史及记录计算。
- 成长统计包含已归档领域并显示归档标记；C20 移除首页成长录入入口，既有成长记录、目标及归档状态继续保留，不因首页变化清理数据。
- 容量限制保持现状：后端 `meals` 为 128 KiB，其他工具为 1 MiB，客户端已有数量／字节限制继续生效。统计读取不会为了补全历史改变留存或写入旧记录。

## 验证

在 `miniprogram` 目录运行 `npm.cmd run test:statistics`，并按受影响范围运行原功能页检查、类型检查与 `npm.cmd run build:weapp`。验收应覆盖六类切换、原有计算口径、空数据、旧存档及格式不兼容、账号不一致／切换、离线读取、记录更新后重开、入口与返回、原功能页分析移出后操作仍可用，以及 360×844、375×667、430×844、768×1024 四种尺寸。

统计为第 12 个分包，共 17 个页面；保留启动、依赖边界和包体检查，主包严格小于 1,500,000 字节，各分包严格小于 2 MiB。上述内容是检查入口与验收范围，实际执行结果按本次交付记录；浏览器预览及构建不能代替微信开发者工具和真机验收。
