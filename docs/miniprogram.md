# Ottlog 微信小程序

源码为 Taro 4.2 + React，独立原生页面复用现有 ASP.NET Core API，不需要微信云开发。网页与后端保持原有行为。

当前开发规则见 [AGENTS.md](../AGENTS.md)、[Design.md](../Design.md)；P01–P12 已于 2026-10-04 确认，正式决定与实现状态见 [决策记录](decisions.md)。后续功能开发只修改小程序，不默认同步网页。以下使用说明描述当前实现，尚未实现的已确认要求单独列出；历史验收记录不代表本次已重新执行。

## 页面与手机操作

底部五个入口为 **今日、待办、领域、习惯、我的**。番茄钟从首页快捷方式或全部功能进入。阅读从首页或功能目录进入。保留 Tau 标志、深色底色和选境配色，录入使用底部编辑器，主要操作兼顾底部安全区。当前日期和部分分类仍使用原生选择器；后续需要展开选择或配置的普通选项默认使用应用内独立小窗，遵循尽量少用系统弹窗、同类表达简洁一致的 [C12／C13／C41 规则](decisions.md#已确认)，不以现状作为新增选择控件的默认方式。

主要工具页面采用「整屏核心操作，下滑查看更多」。首页按 C48 保留快捷入口和全部入口两段，移除领域进展及旧汇总／最近活动整屏和成长进步录入；首屏直接翻到全部入口，返回直达首屏。领域列表与单个领域详情通过页面导航切换。待办首屏显示完整四象限；计时、打卡、记录和选择页将当前操作放在首屏。完整列表、历史、设置等内容放在下方，底部的方向按钮也可点击跳转。页内返回统一为箭头＋「返回」按钮。

待办、领域与习惯主页面的名称显示在导航栏，内容区直接呈现操作与业务内容。领域列表省去页内重复的“领域”大标题，卡片中的领域名与具体分区标题保持显示；同级页面布局约定见 [C15](decisions.md#已确认)。

习惯功能在顶部导航和首页快捷入口中统一显示为「习惯」（[C16](decisions.md#已确认)）；具体操作按其动作与状态表达，文字按钮命名遵循 [C17](decisions.md#已确认)。

普通页面复用 `CoreScreen`、`MoreSection` 和 `PageScroll`；选择画布保留原生整屏色块。首屏以可用视口为最小高度，展开筛选或较长的自定义内容可以自然增高，避免裁掉操作控件。小屏优先保证文字可读、按钮易点，必要时减少首屏可见卡片并滚动，不固定要求显示八张。四象限内仍可分别滚动任务列表。内部滚动条统一隐藏并提供清楚滚动提示的规范已确认，目前部分列表仍待调整。

多边形选境保留全屏色块、点击扩散、进度与回看；手机待办通过点选象限完成归类，不依赖桌面拖拽。选择导航不会重复写入选餐结果。减少动态效果的系统偏好下保留颜色反馈。

普通新建任务默认无日期时间、无优先度，从象限创建时沿用对应优先度（C47）；创建与编辑通过标题上方的日程按钮打开共用面板，空日程仅显示「日期」，设置后显示简短摘要（C28）。年月、时间、提醒、重复与提醒日期按 C41 使用独立小窗，主日历保持完整和原位置。关闭子窗保留当前日程草稿，面板确认只回填任务草稿，最终保存任务才落盘；循环和下一步在完成时生成。具体行为见 [任务与四象限](todo-miniprogram.md)。微信提醒已接入用户提供的模板，后端 AppSecret 仍需配置，按 [微信提醒配置](wechat-reminders.md) 开通后才能发送；选择提醒时间不等于微信已授权。

任务、便签、习惯新增与编辑的优先度按 C40 使用标题最右的单按钮，省去上下箭头；点击打开相邻的独立窄浮窗，四项以对应颜色的旗帜图标＋「高优先度／中优先度／低优先度／无优先度」竖排，宽度按 C59 收紧到 136px，保留选中状态及选择后收起。习惯页与领域详情仍共用同一编辑器，保存修改同一条习惯。

习惯页与领域详情的习惯详情按钮在未完成时显示「已完成」，点击记录今天完成；完成后显示「撤销完成」，可撤销此次完成。暂停的习惯显示「已暂停」。按钮文案统一采用简洁、规范的表达。

默认的「力量训练」「有氧运动」为两个习惯，分别打卡、编辑、暂停和选择专注（C54）。旧默认合并项会在读取习惯存档时拆分，原 ID 与历史继续保留在力量训练，有氧运动从独立打卡开始；已改名／删除的习惯不补回，已有同领域有氧不重复。若已有 80 个习惯或整份存档容量不足，保留原合并项与全部记录，腾出空间后重新读取再拆分。规则见 [C54](../Design.md#力量训练与有氧运动c54)。

习惯卡保留闪电累计打卡天数与火花连续打卡天数（C21），未打卡时显示零值；习惯主网格、待打卡推荐、全部／历史／管理列表及领域详情读取同一份打卡历史，完成／撤销与跨日后同步更新，迁移统计时不能移除卡片进度标记。

习惯页和领域详情点击习惯卡文字后，直接查看同一个习惯月历（C27）：月打卡、总打卡、月完成率、当前连续四项数字，42 格月份日历及月打卡日志。可切换月份或回到本月；日期格用于查看，补记和撤销仍从原七日历史入口操作。详情共用原习惯 ID 和 `reminders`，统计中的综合功能继续保留。习惯编辑的备注标题简化为「提醒自己的话」，不再显示「可选」，仍可留空。

习惯详情按 C32 使用共享日历的详情布局，面板高度为 `min(620PX,100%)`，最大高度为实际可用视口的 100%；默认完整显示四项统计、42 格月份日历、图例和日志／专注按钮，最后一周不能被底部按钮遮挡。月日志从明确入口展开，专注与日志同行；超过 32 字的标题默认最多两行，通过旋转箭头展开完整原文。短备注直接显示，超过 48 字或多行的备注通过「提醒自己的话」展开全文。标题和备注仅作详情阅读摘要，编辑表单备注框仍常显。只读日期行至少 30px，按钮至少 40px；统计页沿用原日历模式，实际可见位置验收见 [Design.md](../Design.md#默认视图完整性c32)。

「统计」从首页全部功能、可选快捷方式及「我的」工具区打开，分别查看待办、专注、习惯、饮食、领域和成长六类（C18）。原功能页保留操作、当前状态和历史编辑，原分析图表及汇总迁至统计；领域主列表的进展摘要、习惯卡进度及单习惯详情月历分别为 C38／C50、C21、C27 的明确展示例外，首页领域进展屏已按 C48 移除。具体迁移范围、计算口径及账号限制见 [统计说明](statistics-miniprogram.md)。统计复用原工具状态，不新增业务存储键，不复制或删除已有记录。

## 内容分组小标题（C67）

内容分组小标题按 [C67](../Design.md#通用小标题c67) 统一复用 `SectionTitle`，采用「记录与生活／更多快捷方式」的 14px／600、行高 1.4、灰蓝色格式；「我的快捷方式」「待打卡习惯」、列表和记录分组同级显示。宽屏不放大，长标题完整换行；同一标题行中的计数、说明和操作按钮保持独立，页面主标题、实体名称与表单字段沿用自身层级。实际覆盖与回归见 [开发说明](development.md#通用小标题c67)。

## 页面功能栏与分类（C51）

上方已有功能统一按「排序、筛选、管理、创建」从左到右排列，创建最右；缺少某项能力时省略，排序与筛选都用文字。分类另放在下一行，统一使用下方 C53 的原习惯页样式，可横向滑动选择，不与操作按钮混排。习惯首页已删除「全部习惯」入口，向下仍可查看完整列表和打卡日历，顶部管理进入原习惯管理区。便签排序独立于筛选窗口，标签在独立分类行选择；待办状态沿用原筛选含义并另占一行，首页按后续 C66 将快捷记录放到首屏底部，排序／管理置于快捷方式独立功能栏。详见 [C51](../Design.md#页面功能栏与分类行c51)。实际完成的检查见 [开发说明](development.md#页面功能栏与分类行c51)。

## 分类栏操作（C53）

分类栏沿用原习惯页样式：未选中透明无框，选中显示浅绿底与深绿文字。点击分类切换原列表、状态或模式；分类较多或名称较长时，左右滑动同一行查看完整名称和末项。习惯、待办、便签、文章、饮食、专注、统计，以及习惯下页和图标库／习惯选择／待办选择弹层使用同一分类组件；禁用分类不响应点击。分类与功能栏独立，原筛选和保存含义保留。设计主说明见 [C53](../Design.md#通用分类栏c53)，本轮实现与验证状态见 [开发说明](development.md#通用分类栏c53)。

## 按钮与分类组件

小程序按钮按 [C60 分层规范](button-guidelines.md) 根据功能、所在组件和局部层级选型，尺寸与颜色层级分别决定；同场景同类保持一致。compact／regular／large 为 40／44／48px 触控下限，宽度按内容或填满所属组件，高度随长文案增长，不随宽屏 rpx 无限放大。表单选项、页面分类、优先度、创建／返回、图片覆盖层和业务卡片采用各自共用规格；分类栏继续 [C53](../Design.md#通用分类栏c53)，优先度按 C40／C59 使用独立旗帜与窄浮窗，便签颜色使用色点。新规格已由共用组件支持，其他旧页面在相关修改中逐步接入，实际范围见开发说明。

首页「创建任务」「创建便签」快捷方式的名称旁不加小加号，保留原功能图标与用户自定义名称；首页输入及领域目标设置框旁按 C65 仅显示「＋」，其他功能栏紧凑创建按钮保留加号与完整动作文字。业务卡片、日期格和完成标记沿用自己的状态色及内容布局。实现与实际验证见 [开发说明](development.md#控件外观与复用c39)。

## 实体创建与编辑规范

[C28 共用规范](../Design.md#实体创建与编辑c28) 适用于小程序实体创建和编辑：单选按钮打开悬浮小选项窗；多标签常用项按 [C46](../Design.md#标签行宽度分配c46) 等宽分配可用空间并尽量铺满一行，末端紧邻箭头展开悬浮多选窗；可自定义的选择项常用在前、创建默认最常用、末尾输入自定义内容。备注在标题下默认显示，图标在标题左、优先度在标题最右，日程在标题上方；字段仅按实体已有能力显示。

展开时上下 chevron 顺时针旋转 180°，收起时逆时针旋转 180°，同类入口使用同一组件。

本轮已迁移任务、习惯页与领域详情共用的习惯编辑器、备忘录、饮食营养记录／常用餐单、领域「记录进展」及管理员餐厅标签。领域创建原有的图标左／名称右位置保持；领域目标与格言沿用单正文表单；领域记录按 C49 使用上下双框，保留各实体原有字段。营养值不生成预设选项，编辑继续保留原值。

字段选择共用 `components/form-options.tsx` 的 `ChoicePopover`、`SingleChoiceField`、`TagChoiceRow`、`CustomChoiceRow`；需要展开的设置／选择项按 C41 默认使用独立小窗，普通小窗相邻，完整日历或含自定义输入的复杂设置可居中；`lib/form-options.ts` 从当前账号原数据计算常用顺序，不另存频次缓存。共享 `SelectChevron` 及任务日程／月份、阅读筛选、领域记录更多、专注来源等展开入口使用旋转上下 chevron，既有首页快捷设置及任务完成折叠调用处同步更新。以上为实现范围，验证仍按实际执行环境报告。

## 任务备注 Markdown 与图片（C44）

任务备注和备忘录正文复用同一书写／预览及插图编辑区。任务备注位于标题下，工具栏与图片属于备注编辑区，下一步在其后；保存及重开保留 Markdown 和图片，切换任务／备忘录带入正文与图片。每条最多 6 张，沿用压缩和空间限制；操作与规则见 [任务说明](todo-miniprogram.md)，实际验收见 [开发说明](development.md#任务备注与共享-markdown-编辑c44)。

备忘录的标签按 [C45](../Design.md#备忘录标签位置c45) 位于颜色／置顶设置之后，是表单最后一个字段；统一创建和原便签编辑采用同一顺序。

便签颜色按钮按 [C62](../Design.md#便签颜色入口c62) 显示色点、当前颜色名称与展开箭头，点击按钮选择颜色；省去「颜色 ·」前缀，选择和保存操作沿用原规则。

实际标签名称前按 [C63](../Design.md#标签显示前缀c63) 显示一个 #，例如「#工作」；常用行、完整选项、标签筛选及已有卡片／详情同步。原标签输入与保存不变，已有 # 不重复；全部／不限、分类和用餐时段等普通选项保留原文。

## 任务与备忘录共用创建（C34）

任务与备忘录以任务表单为基准共用一个新建弹窗：首页原生单行输入按 C66 位于首屏底部，右侧按 C65 仅显示「＋」，点击就地展开；排序／管理放在「我的快捷方式」独立功能栏，创建快捷入口调用同一弹窗。弹窗按 C49 可切换任务／备忘录／记录进展。任务与备忘录共用标题、Markdown 备注／正文、图片、标签和优先度，各类型专属内容分别保留；进展双框与领域独立保留，最终只保存当前类型；已有记录编辑仍保留原类型和 ID。共享组件和本机草稿机制已实现，详细交互见 [C34](../Design.md#任务与备忘录共用创建c34)，实际验证和剩余环境见 [开发说明](development.md#任务与备忘录共用创建c34)。

标签从同账号任务与备忘录原记录合并频次，兼容任务旧分类，不新增标签库。普通新建任务与备忘录按 [C47](../Design.md#新建默认优先度c47) 默认无优先度，象限任务沿用对应优先度；手动选择、类型切换和草稿恢复保留当前值，历史备忘录缺省为无，卡片显示对应颜色的右上角角标；原备忘录排序不因该字段改变。切换保留完整原文，保存时分别校验任务标题／备注 100／10000 字与备忘录标题／正文 80／6000 字，超限提示后保留输入。

创建草稿按账号存本机，关闭后重开恢复，游客单独隔离；打开类型由入口指定。已有草稿标题非空且与首页新输入不同时保留原标题，将新输入追加到正文并提示；相同输入重开不重复追加，也不覆盖在弹窗内改过的标题。读写或图片失败保留内容，异步回调和保存核对账号；本机未持久化时保留界面与同一记录重试，保存成功才清理草稿。草稿存储结构及完成范围见 [开发说明](development.md#任务与备忘录共用创建c34)，不代表其他编辑器的 P08 全局恢复已完成。语音使用输入法自带语音转文字，不另接入录音识别服务。

## 首页两屏与领域入口（C48）

首页依次为快捷入口和全部入口两屏，原领域进展及“与昨日对比”对应的汇总／最近活动整屏均已移除。首屏下滑或方向按钮直接到全部入口，点「返回」回到首屏。原「领域进展」快捷方式直接打开领域主界面，再点击领域卡片进入详情；创建输入、格言与其他入口保留。

全部功能按 [C68](../Design.md#全部功能的操作与界面c68) 在第二屏分为「快捷操作／功能界面」两列目录。「便签」打开已有便签列表，「创建便签」打开共用创建弹窗；「开始番茄钟」执行开始／继续，「番茄钟」只打开原界面；「数据」打开现有统计页。原更多快捷方式已合并到目录，不单独重复显示，保留自定义名称、图标配色、原设置与排序；完整目录不受个性设置隐藏影响，最近打开仍位于其后。使用步骤见 [首页说明](home-shortcuts.md)。

领域主列表按 [C50](../Design.md#领域首页卡片c50) 在各尺寸使用每行两张领域卡，保留图标、领域名称、原三类完成数和一条连续蓝色长期／粉色短期／绿色习惯进展线；先不显示长期／短期目标内容和空目标占位，点击卡片进入详情查看与编辑。每次完成的示意单位仍为长期 6、短期 3、习惯 1；全列表最大加权总数（至少 1）作为共同刻度，长期单次最长、习惯最短。这是完成数量的视觉比较，不是百分比完成率或新的积分。领域主列表复用 `DomainProgressSummary`，不复制目标、习惯或计数。默认八张卡在四种验收尺寸完整显示，更多领域和管理状态保留明确滚动，不能裁掉列表来消除微小滚动。管理操作按两行两列排布，保留原排序、编辑、删除和触控尺寸。

- 短期目标、长期目标分别统计该领域当前保留的已完成目标历史，累计至当前时间；进行中或未来完成的目标不计入，撤销后立即从领域进展数量移除。
- 领域主页面左上角不再显示「长期／短期／习惯」文字图例（C55），管理和创建仍在右侧；卡片内三类完成数和进展线继续显示。
- 领域卡图标统一放大为 40×40px（C58），接近习惯卡整体图标区域的比例；名称、计数及进展线保持清晰分隔，默认八域完整显示。
- 领域卡图标左右留白按 C64 对称：图标到卡片内左边界与到正文均为 12px，窄屏与宽屏使用同一间距。
- 今日习惯统计当前本地日期中已完成的启用习惯，每条共享习惯最多计一次；昨天或未来的打卡不计入，暂停、删除或撤销后重新计算。读取原打卡历史及归档，明确的当天撤销优先于归档。
- 习惯从 `reminders` 读取，关联沿用 `alignHabitDomain`：已有 `domainId` 优先，旧无 ID 的分类兼容当前领域名称及既有旧分类映射；改名保留稳定关联，已删除的显式领域关联不会因同名新领域恢复。旧 `Domain.habits` 不参与计数。
- 两个来源 `ready`、`owner` 相同且存档有效后才展示；读取中、账号未一致或格式不兼容时显示状态与重试，不把错误数据当零值。领域进展沿用共享状态层和账号隔离，不写入新的计数、工具存档或业务副本。

首页不再提供各成长领域的小／中／大进步录入、成长目标管理或归档入口。旧 `growth` 数据保持原样，统计的成长分类继续显示原记录和图表，不将成长积分或旧目标转换为 `domains` 的目标或习惯。快捷方式沿用 `growth` 键，旧默认名「成长足迹」迁移为「领域进展」，其他自定义名、颜色、顺序和样式保留，详见 [首页快捷方式](home-shortcuts.md)。

## 账号与保存

底部「领域」打开入口列表，默认为成长、工作、英语、健身、生活、心理、摄影、自媒体；点击卡片进入单个领域详情。右上角「＋ 创建领域」打开创建表单，「管理」可编辑名称和图标、用上下箭头排序或删除。P06 已确认：删除普通领域时移除该领域的目标和记录，共享习惯保留并转为未分类，确认框必须明确各类数据去向。当前共享习惯仍保存在 `reminders`，失去领域关联后显示为未分类；删除确认仍有旧的“删除习惯”表述，文案待修正。旧存档未设置图标时使用对应领域的默认图标。

「记录进展」打开任务／备忘录／进展的共用创建弹窗。领域选择在上，下面依次为正记录和负记录两个 Markdown 输入框，提示分别为「有什么进展？」及「遇到了什么问题？」；各支持书写／预览和图片。无需选择正负，点击「保存记录」只创建有文字或图片的对应记录，两框同时有内容则一次保存两条。默认选择未分类，详情入口的新草稿带入当前领域；切换类型和关闭保留三类输入，任务／备忘录共用正文，进展双框及领域独立保留。规则见 [C49](../Design.md#进展记录与共用创建c49)。未分类目前在首次保存时创建普通领域，不会因打开或取消而创建；P05 已确认改为固定系统领域、始终可选、不能改名或删除、不占自建名额，尚待实现。长期与短期目标使用长条卡片，可完成并撤销；「已完成目标」打开历史列表，累计数字在统计的领域分类查看；已完成目标使用圆内实心点。领域习惯每屏两行、每行两个，更多卡片横向滑动；图标用于今天打卡及撤销，点击卡片文字查看后可直接点击「编辑」，与习惯页共用表单修改原习惯，保留打卡历史；更改领域后卡片移到对应领域。当前按优先度高到低、创建时间新到旧排序；拖动后恢复持久自定义顺序的规则见下方待实现清单。优先度统一为右上角小三角：高红、中黄、低绿、无灰。正记录／负记录标题旁不显示「写一句」，点击标题或对应半区录入，× 删除。桌面 Esc、关闭按钮或遮罩可关闭创建弹窗；创建任务／备忘录／进展的本机草稿已共用，其他编辑器恢复机制仍未全部实现。

领域管理复用现有账号存储队列，以独立的 `domains` 数据保存；不导入或修改原 `growth` 成长足迹的进步积分及历史。领域习惯从共享 `reminders` 读取，不新建独立起步习惯；旧内嵌 `Domain.habits` 仅保留兼容读取。目标与历史初始为空。后端仅扩展工具键，无需为该键新增数据库表；更新后端并重启后才可同步新工具。运行 `npm.cmd run test:domains` 检查领域模型和交互；微信原生键盘、返回与安全区仍需开发者工具/真机验收。

记录进展的领域选择按 [C61](../Design.md#记录领域选择c61) 为横向填满的按钮，显示当前分类图标、名称与展开箭头。点击按钮打开独立分类窗，按带图标的领域名称选择；选择后自动收起并更新按钮，点击窗外关闭则保持当前分类。图标与领域卡片一致，长名称可完整换行；未分类的选择、草稿与保存含义保持原规则。

主页快捷方式右上角的 排序图标进入直接拖动排序，「编辑」按钮打开功能选择面板；普通浏览时长按入口不会进入排序。名称、颜色和大小样式位于修改面板的展开项中。当前布局保存在本机，支持取消修改和恢复默认；P09 已确认个性设置随账号同步，目前待实现，详见 [主页快捷方式](home-shortcuts.md)。

日常工具使用现有 `/api/personal-tools/{key}`，兼容网页的 `todos`、`memos`、`reminders`、`pomodoro`、`dining`、`meals` 数据。Tau 比较餐单、双语推荐目录与个人餐单保持各自的数据来源。

- 未登录：保存在本机；新安装无账号凭据时，断网也能开始使用。
- 已登录：按账号分别缓存，修改先落到本机，再串行同步；网络失败保留待同步记录。
- 再次打开页面或点击重试：重新读取，并补发该账号尚未同步的修改。
- 登录和退出：立即重新确认身份；发送前核对账号，避免旧页面把记录写入新账号。
- 访客记录不自动合并进账号。退出后可继续使用原本的访客记录。
- 不兼容的数据不自动覆盖；支持的记录尽量保留网页附加字段。

当前接口按整个工具状态保存，多设备编辑同一工具仍受现有服务端的“最后一次保存”机制影响，尚无逐条合并。P10 已确认按记录 ID 自动合并的方向，不能继续以整份数据静默覆盖作为目标行为；同一 ID 同时编辑、编辑与删除相遇等具体冲突规则尚待定义。
