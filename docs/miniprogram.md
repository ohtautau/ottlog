## 页面与手机操作

含「全部」的横向分类栏按[C229](../Design.md#横向分类栏固定全部c229)把「全部」固定在左侧第一位，后续分类在右侧滑动，覆盖习惯领域、便签标签、文章分类、图标库及专注选择习惯的分组。原名称、粗体字号、40px触控与「全部」清除对应分类条件的含义保持；习惯的一格半前置位置只计算右侧滑动分类，选「全部」回到右侧起点。静态／网格中的「全部」及没有「全部」的分类栏保持原布局，账号、筛选和存档不变。

习惯、任务和便签筛选按C228共用标题、字段、选项、搜索与底栏，字段组距8px、标签下距6px、网格6px，不再叠加按钮上下外边距；搜索框统一44px外框、24px文字行并保留原清空符号。原关键词、实时数量、各页重置范围、多选或逻辑、C227默认高亮、账号及关闭行为保持。

习惯页按C227在默认优先度降序、默认进行中且没有其他条件时，不高亮顶部排序／筛选符号；窗口内选中项保持，其他自动排序和非默认筛选沿原高亮。排序窗删去确认上方说明及下方分隔线，保留原确认与拖动保存。

习惯页按C221将时段栏与自由／提醒统一12px字号和整行宽度，略收紧标题间距、移除提醒上方线；顶部领域选中时尽量在前面保留一格半分类，按C229排除固定「全部」、只参考右侧滑动内容，首尾及长名称自动限位。

便签颜色按C220直接显示在列表卡片和阅读正文上；创建、编辑和滑动预览也跟随所选颜色，原保存和筛选不变。

弹窗末行按钮按C219统一到下边界8px；浮窗与底部导航不重复加安全区，贴屏幕底部的其他窗口只保留必要安全区，不叠加额外空白。

便签内容展示按C218在正文／图片下方独立一行右对齐置顶符号，点击可置顶／取消置顶，窗口保持打开，不显示置顶文字。

弹窗按C217统一省去底部单行按钮上方的分隔线，包含同排多个按钮；按钮间距和底部安全区保持，正文分段线不变。

编辑窗口按C216共用习惯编辑的标题字号、字重和上下左右间距，覆盖习惯、任务、便签、快捷方式、领域／目标、记录、格言、饮食、成长和专注设置；原关闭、保存及内容操作保持。

领域详情按C213在右上角显示「＋创建记录」，打开即选择当前领域；未提交草稿保留内容并跟随当前领域，已提交待重试记录仍使用原目标。

记录按C212直接显示正负内容，不显示双栏标题；进展创建和记录编辑不再有插入图片按钮。原图片与旧草稿仍能显示／预览，保存文字不删除原图，便签和任务备注仍可插图。

领域页按C211在首屏后固定显示「未分类」卡，已有额外普通领域仍续接显示。未设置内容时也有空卡，浏览不写存档；详情聚合原未分类记录及未关联／已删除领域习惯，原ID／历史保留。未分类不参与普通领域排序，不可改名／删除，首屏仍只显示普通领域卡。

领域隔离预览按C210一次性补充成长／工作／生活／自媒体四条较新的负记录，顶部最新十条可以同时看到正负内容。已有预览冷启动时自动追加，原记录及编辑／删除保留；只在build:preview中生效，普通游客与账号数据不变。

进展按C203统一普通文本：创建双框及已有正负记录编辑无Markdown模式切换，最近记录／领域详情原样显示换行及旧标记。原图片、独立正负、上框标题互通、原子保存、原ID／日期及账号草稿守卫保持；任务备注与备忘录仍支持Markdown。

底部五个入口为 **今日、待办、领域、习惯、我的**。番茄钟从首页快捷方式或全部功能进入。阅读从首页或功能目录进入。保留 Tau 标志、深色底色和选境配色，录入使用底部编辑器，主要操作兼顾底部安全区。当前日期和部分分类仍使用原生选择器；后续需要展开选择或配置的普通选项默认使用应用内独立小窗，遵循尽量少用系统弹窗、同类表达简洁一致的 [C12／C13／C41 规则](decisions.md#已确认)，不以现状作为新增选择控件的默认方式。

主要工具页面采用「整屏核心操作，下滑查看更多」。首页按 C48 保留快捷入口和全部入口两段，移除领域进展及旧汇总／最近活动整屏和成长进步录入；按后续 C82 滑动往返，不显示底部下箭头和第二页返回按钮。领域列表与单个领域详情通过页面导航切换。待办仅完整四象限单页，不再有同步说明第二页；习惯按 C84 保留网格单页，补记在独立窗口完成；便签按 C158 使用首屏内部滚动列表，移除第二页，错误与重试保留首屏；计时、打卡、记录和选择页将当前操作放在首屏，完整列表、历史、设置等内容放在下方，滑动切换保留。其他页原返回按钮和业务跳转保留。各功能页正常「保存在本机」说明按 C83 集中到「我的」的「数据保存与同步」，必要错误和重试仍在相关页面显示。

待办、领域与习惯主页面的名称显示在导航栏，内容区直接呈现操作与业务内容。领域列表省去页内重复的“领域”大标题，卡片中的领域名与具体分区标题保持显示；同级页面布局约定见 [C15](decisions.md#已确认)。

习惯功能在顶部导航和首页快捷入口中统一显示为「习惯」（[C16](decisions.md#已确认)）；具体操作按其动作与状态表达，文字按钮命名遵循 [C17](decisions.md#已确认)。

普通页面复用 `CoreScreen`、`MoreSection` 和 `PageScroll`；选择画布保留原生整屏色块。首屏以可用视口为最小高度，展开筛选或较长的自定义内容可以自然增高，避免裁掉操作控件。小屏优先保证文字可读、按钮易点，必要时减少首屏可见卡片并滚动，不固定要求显示八张。四象限内仍可分别滚动任务列表。内部滚动条统一隐藏并提供清楚滚动提示的规范已确认，目前部分列表仍待调整。

- 未登录：保存在本机；新安装无账号凭据时，断网也能开始使用。
- 已登录：按账号分别缓存，修改先落到本机，再串行同步；网络失败保留待同步记录。
- 再次打开页面或点击重试：重新读取，并补发该账号尚未同步的修改。
- 登录和退出：立即重新确认身份；发送前核对账号，避免旧页面把记录写入新账号。
- 访客记录不自动合并进账号。退出后可继续使用原本的访客记录。
- 不兼容的数据不自动覆盖；支持的记录尽量保留网页附加字段。

当前接口按整个工具状态保存，多设备编辑同一工具仍受现有服务端的“最后一次保存”机制影响，尚无逐条合并。P10 已确认按记录 ID 自动合并的方向，不能继续以整份数据静默覆盖作为目标行为；同一 ID 同时编辑、编辑与删除相遇等具体冲突规则尚待定义。

cd E:\projects\ottlog\miniprogram

```powershell
$env:TARO_APP_API_BASE_URL = "http://192.168.1.100:5229"
npm.cmd run build:local
```
