# 按钮分层与动态尺寸（C60）

确认日期：2026-10-06。适用于小程序的新增按钮、共用按钮组件及相关页面修改。正式决定见 [决策记录 C60](decisions.md)，视觉规则入口见 [Design.md](../Design.md#按钮分层与动态尺寸c60)，实际代码迁移与验证见 [开发说明](development.md#按钮分层与动态尺寸c60)。本文件为规则主说明；规则已确认不表示所有旧页面已完成迁移。

## 统一的依据

按钮先按所在组件、动作功能、操作层级和布局条件分类，再统一同类场景的外观与行为。同一组件内承担同类动作的按钮，使用相同的尺寸档位、文字层级、间距和状态反馈；不同组件的按钮可以有不同尺寸和布局。例如页面功能栏的「创建任务」与编辑弹层底部的「创建任务」，动作名称相同，前者是紧凑入口，后者是正式提交，应共享创建语义并各自使用相应规格。

C60 替代 C39 将「主操作」机械对应大按钮、将其他按钮机械对应同一个小按钮的做法。按钮层级、危险意图、尺寸和宽度分别决定；页面不能通过局部字体、颜色或固定高度绕过共用规范。C17／C37 的命名和图形语义、C28／C36／C41 的选择交互、C29 的安全区、C33 的操作顺序，以及账号、草稿和保存规则继续有效。

## 分类步骤

1. **确定交互类别。** 执行动作使用 `ActionButton`；表达单选／多选的当前值使用 `ChoiceButton`；页面分类使用 `CategoryRow`／`CategoryButton`。实体创建入口使用 `CreateButton`，返回使用 `BackButton`。业务卡片、日期格和完成标记先使用各自专用组件。
2. **确定所在组件。** 从下方场景矩阵选择页面功能栏、字段触发器、选项窗、弹层操作栏、列表行等规格。相同文字出现在不同组件时，分别遵循所属场景。
3. **确定操作层级。** 该操作区域中最需要完成的动作采用 primary；明确的替代动作采用 secondary；辅助和低频动作采用 quiet。纯图标采用 icon 外观，另由语义决定是否有危险意图。
4. **确定功能意图。** 删除等危险动作增加 danger 意图；取消、清除筛选、返回和撤销完成按其实际业务处理，不因名称相近自动归为危险动作。危险意图不代替层级，也不添加本次业务并不需要的新确认流程。
5. **确定尺寸和宽度。** 按场景选择 compact、regular 或 large，再选择按内容、填满或同组等分。尺寸是最低触控要求；内容需要更多空间时让宽度或高度增长。
6. **确定状态与无障碍。** 明确禁用、加载、选择、展开和名称来自哪个状态；检查真实节点顺序、图形朗读和点击区域，最后做四尺寸与相应业务回归。

新场景先找矩阵中最接近的用途；确需新的共有规格时，在共用组件或变量中新增具名规则，并记录适用范围。不能用页面名、随意的像素值或 CSS 类名推导业务语义。

## 层级与功能意图

| 维度 | 类型 | 选择依据 | 典型用法 |
| --- | --- | --- | --- |
| 操作层级 | primary | 当前操作区域的主要完成动作，视觉强调最高 | 弹层保存／确认、功能栏创建、筛选查看、专注开始 |
| 操作层级 | secondary | 与主要动作并列的明确替代动作，需要有清晰边界 | 弹层取消、普通编辑、返回、筛选清除 |
| 操作层级 | quiet | 辅助动作，以较低视觉权重保留操作可达性 | 列表行编辑、文字展开、日期回到今天 |
| 展示形式 | icon | 上下文足够明确且已有稳定图形的辅助动作 | 关闭、月份翻页、搜索清空、C56 象限创建 |
| 功能意图 | default | 普通操作，使用所属层级的中性／主操作颜色 | 创建、保存、取消、选择、返回 |
| 功能意图 | danger | 删除记录或具有明确破坏性后果的动作，使用共用危险色 | 删除便签、移除领域、危险图标动作 |

同一操作区域通常只设置一个 primary；多个独立业务区域可以各有自己的主要动作，例如四个象限的创建。选项的选中态表示当前选择，不计作主要提交动作，也不能因为选中就改成大号主提交按钮。

danger 是功能意图，可以与普通、轻量或图标外观组合。列表中的删除可以采用 quiet＋danger，图标移除可以采用 icon＋danger；正式删除确认可以采用强调的危险操作。危险反馈与业务确认沿用原流程，不把所有红色标记、负记录、任务高优先度或「清除筛选」当成删除。

### 视觉令牌

同一类型的颜色、圆角和反馈来自 `components/ui-button.css` 的共用变量。层级与意图选择令牌，不随页面另写一套颜色；需要主题或新环境适配时修改共享令牌及其适用规则。

| 类型／环境 | 文字 | 底色 | 边框与反馈 |
| --- | --- | --- | --- |
| primary | `#18332c` | `#b9dbca` | 边框同底色 |
| secondary／普通未选项 | `#c7d7df` | `#20333e` | `#3b505a` |
| quiet／默认 icon | `#c7d7df` | 透明 | 透明边框；hover／pressed 为 `rgba(199, 215, 223, .1)` |
| 普通已选项 | `#d3efdf` | `#304c42` | `#a4cfbc`；选中时保留该底色，不改字重或尺寸 |
| danger 普通操作 | `#edb8b6` | `#422d34` | `#63404a` |
| danger quiet／icon | `#edb8b6` | 透明 | 透明边框；保留无边框反馈 |
| category 未选 | `#97adae` | 透明 | 无边框；C53，hover／pressed 使用共享浅底 |
| category 已选 | `#284a3a` | `#d7e8dd` | 无边框；C53，选中时保持浅绿底 |
| overlay icon | `#f3eddf` | `rgba(16, 25, 35, .85)` | 透明边框；hover／pressed 为 `rgba(16, 25, 35, .96)`，保持图片上可辨认的高对比 |

overlay 是图片上的可读性环境，其高对比图形优先使用该环境令牌；危险功能仍由动作名称和原业务规则表达，不能在复杂照片上仅靠红色辨认。优先度旗帜、颜色选项色点、卡片业务色和日期状态不纳入按钮文字令牌；保留各自组件和明确含义。

| 所在组件／场景 | 功能与层级 | 默认尺寸 | 宽度与排列 | 共用组件和约束 |
| --- | --- | --- | --- | --- |
| `PageToolbar` 页面功能栏 | 排序／筛选／管理为 secondary 或已有 quiet；创建为紧凑 primary | compact，至少 40px | 按内容宽度；6px 间距，靠右；真实顺序排序→筛选→管理→创建 | `PageToolbar`＋`ActionButton`／`CreateButton`；不增加页面没有的功能，不把分类混入该行 |
| 编辑或排序中的功能栏 | 保存 primary，取消 secondary | 两者 compact | 同一行、同一尺寸；保留原顺序和回调 | 沿用该功能栏；保存不因 primary 自动增至 48px |
| 文本框或目标设置框旁创建 | 上下文已明确创建对象，primary；C65 仅显示加号 | 默认 compact，至少 40×40px；独立宽行可随组件使用 regular／large | 位于输入右侧，不挤压输入；目标行可沿所属行增高，图形保持居中 | `CreateButton iconOnly`＋`AddSymbol`；完整动作和对象保留在无障碍名称；不改其他功能栏创建或正式提交 |
| 表单字段选择入口 | 打开选项窗，属于字段控制；打开态表示展开 | compact；独立宽行可用 regular | 短字段按内容；整行字段填满，值与箭头不挤压 | `ChoicePopover`／`SingleChoiceField`／`SelectTrigger`；保留展开状态和 8px 相邻定位；优先度按 C40 无箭头，记录领域按 [C61](../Design.md#记录领域选择c61) 使用 regular／fill 与原领域图标 |
| 普通选项浮窗 | 单选／多选属于选择，不是提交 | compact；需大行距的独立列表可用 regular | 同组等宽栅格或单列填满；列数按完整文字与可用宽度选择 | `ChoiceButton`、C35 等宽布局；末行保持原列宽，无空占位；长选项可换行 |
| 优先度浮窗 | 选择高／中／低／无优先度 | compact，至少 40px | 单列等宽；目标面板宽度 136px，受实际可用视口限制 | `PriorityOptions`＋`PriorityFlag`；完整四项名称，旗帜与文字分离，保持 C59 右侧留白约束 |
| 页面分类、状态／模式行 | 切换列表范围／模式 | compact，至少 40px | 单行，少量分满一行，更多或长名称横向滚动 | `CategoryRow`／`CategoryButton`；保持 C53 无框、浅绿选中、6px 圆角、2px 间距，不能换成普通选项外观 |
| 表单常用标签行 | 快速多选；末端展开完整列表 | compact | 标签等宽分配剩余宽度，末端箭头紧凑；长名按 C46 单行省略 | `TagChoiceRow`；浮窗保留完整名称，空计数／空列表不占位 |
| `SheetActions` 正式表单底栏 | 保存／创建／确认 primary，取消／清除 secondary；删除按 danger | 同组 large，至少 48px；完整选择窗的简单完成行可同组 regular | 按既有结构填满或等分；一组主／次动作使用同一档位，字多时一起增高 | `SheetActions`＋`ActionButton`；C29 单一分隔线、按钮到底部 8px、tabBar 不重复补安全区 |

| 关闭、清空、翻月等辅助图标 | 明确上下文的 icon；置顶等可选图标属于选择 | compact，至少 40×40px | 独立完整点击区域；图形居中，不能扩大后遮挡邻项 | `ActionButton appearance='icon'` 或 `ChoiceButton iconOnly`；文字名称用无障碍属性提供 |
| 图片上的移除等覆盖图标 | 图片附件的局部动作，icon；按实际功能提供 danger 意图 | compact，至少 40×40px | 叠放在图像边角，完整圆形点击区域；不依赖照片本身的颜色形成边界 | `ActionButton appearance='icon' context='overlay'`；共享圆形、深半透明底及高对比图形，悬停／按下反馈仍清晰；禁用保留深底、文字稍淡，不对整个点击框降低透明度 |
| 四象限右上角创建 | 创建该象限任务；C56 明确纯加号入口 | compact，至少 40×40px | 固定在标题区右上角；为标题与说明预留区域 | `ActionButton`＋`AddSymbol`；每项明确对象名称，仍带入对应优先度，不恢复底部创建栏 |
| 返回入口 | 返回上页／上一区域，secondary | compact；独立导航区域可 regular | 按内容宽度，保留返回图形与文字 | `BackButton`；不替换成关闭或只留下不明符号 |
| 专注主动作区 | 开始／继续为 primary；暂停／结束按原状态和层级区分 | large，至少 48px；专用主动作可通过共享专注组件进一步增加操作区域 | 主动作按区域填满或组内等分，不随屏幕等比扩大；辅助设置保持 compact | 共用动作按钮＋专注页面结构；保留计时、暂停、完成与撤销语义，不把全部辅助按钮做成同等强调 |
| 首页快捷卡、全部功能入口 | 导航或打开创建，不是表单提交 | 由卡片／入口专用组件决定；操作触控不少于 40px | 保留卡片两列、图标与名称层级；名称可用完整布局 | 不强制换成标准矩形按钮；创建快捷方式名称旁按 C39 不加小加号 |
| 习惯／领域业务卡、日期格、完成标记 | 内容导航、日期选择或业务完成状态 | 由各专用组件决定；可操作区域不少于 40px | 内容、统计、业务色标和状态几何由专用组件负责 | `HabitCard`、`DomainProgressSummary`、`HabitCalendar` 等；不以按钮统一为由抹掉卡片比例、日期状态或业务颜色 |

## 尺寸、文字与宽度

### 尺寸档位

| 档位 | 触控高度下限 | 文字默认值 | 适用条件 |
| --- | --- | --- | --- |
| compact | 40px | 14px／500 | 功能栏、字段短入口、分类、选项、辅助动作；可点击图标的宽度也不少于 40px |
| regular | 44px | 14px／500 | 独立列表操作、宽行字段、简单选择窗操作；同组使用同一规格 |
| large | 48px | 16px；primary 600，其他 500 | 正式表单底部、专注主要操作；主／次动作可以同用 large，并以颜色／边界及主要操作字重区分层级 |

40／44／48 是触控下限，不是锁死的高度。文字换行、加载状态、用户内容或专用组件需要更多空间时，使用内容高度与共享内边距增长；不能用固定 `height`、裁切或负位移把文字塞回最小框。图标单行控制可保留紧凑方形布局，但其规格仍由尺寸档位决定，不能低于档位触控面积。

尺寸与层级解耦：compact primary 和 compact secondary 可以并列；large secondary 可以和 large primary 一起用于正式操作栏。字号随尺寸档位选择，不随是否选中、是否危险或是否禁用变化；基础字重为 500，large primary 为 600。按钮内子文字继承该档位，页面不再分别覆盖子 `Text` 的字重或行高。

系统字体栈、行高 1.4、零字距由共享变量定义。动作按钮默认圆角 10px；C53 分类保持 6px；卡片、日期、颜色素材和其他专用组件使用自己的已确认比例。不通过变形、缩字或增加阴影提高层级。

### 宽度策略

| 策略 | 规则 | 典型用法 |
| --- | --- | --- |
| 按内容 content | 宽度由图标、文字、间距和内边距决定；不为所有按钮设同一个宽度 | 页面功能栏、返回、行内编辑；优先度窗按 C59 控制内容与右侧空白 |
| 填满 fill | 使用所属区域的可用宽度，保持文字与图标内部间距；不填满整屏外部空白 | 单个表单提交、单列选项、整行字段触发器 |
| 同组等分 | 由父容器的 flex／grid 分配；成员使用同一尺寸档位；减去真实间距后等宽 | 两个底栏动作、C35 选项栅格、C46 标签；末行不拉宽孤项 |

内容宽度受父容器限制；无法容纳时按场景处理长文和排列，不挤压相邻按钮、输入框或业务标题。等宽是同一组的布局关系，不是为整个应用设全局固定按钮宽度。浮窗宽度按真实内容、锚点和可用视口选择，C59 的 136px 为优先度专用宽度，不推广到所有浮窗。

### 视觉图形与触控区域

图标素材尺寸与按钮触控尺寸分开。加号、返回、chevron、旗帜及其他共享图形保持各自规格，外部按钮通过内边距和最小宽高提供触控面积。不能把 40px 点击框理解为 40px 图标；C56 的共享加号仍保持轻量图形，C40 的旗帜保持 16×20px。纯字符图形采用共享图标文字档位，素材不被字符字号规则放大。

图形与文字并列时由共用组件保持图文间距；装饰图形使用 `aria-hidden`，不重复朗读动作名。图形不是唯一反馈：选择状态、禁用状态及危险动作同时保留文字或可访问名称。

## 空间变化与长文字

- **窄屏。** 先保留完整动作名、触控下限和输入宽度，再减少不必要空白。功能栏的业务长标题可另行展示；需要换行时保留真实动作顺序，不把按钮压缩到文字或图形重叠。分类按 C53 横向滑动，标签行按 C46 摘要，选项浮窗按 C35 减少列数或允许完整换行。
- **短屏。** 扣除实际导航栏、固定操作栏和必要安全区，主体提供明确滚动。底部主／次按钮完整可达，默认关键模块保持 C32 完整显示；不能通过减小触控、重复扣导航高度或把控件盖在正文上节省空间。
- **宽屏。** 按钮的文字、图形与触控档位不随 rpx 等比增长；增加的空间优先用于内容宽度、合理列数或专用容器最大宽度。fill 仍填满所属组件，不把内容按钮拉长到整屏。分类的少量项分满行是 C53 的专用规则。
- **长动作名。** 优先使用完整简洁文案并按实际容器换行、增高或调整排列。正式操作栏同组按钮在同一行时保持相同最终高度，不能一项两行而邻项仍贴上沿。不可用省略号隐去保存、删除或创建对象；仅 C46 等已有摘要场景可以省略，完整内容仍可查看。
- **状态切换。** 选中／未选中、默认／加载、启用／禁用保持原位置、同一档位与宽度策略。文案实际增长可以带动高度变化，但不能因为选中时加粗、边框变化或图形突然占位造成无意义跳动。

## 状态和无障碍

| 状态 | 视觉与交互要求 | 验收重点 |
| --- | --- | --- |
| 默认 | 保留所属层级、意图和尺寸档位；普通轻量／图标透明，overlay 保留高对比底色 | 真实字号、边界、图文间距和点击区域 |
| hover | 支持鼠标悬停时，无边框按钮按 C43 显示浅半透明反馈，overlay 使用覆盖环境反馈；移开恢复，已选项保留选择底色 | 悬停／移开底色，几何不变，触屏无残留，不依赖 hover 才能识别动作 |
| pressed | 小程序通过共享 `hoverClass` 显示按下反馈；选中底色保持清晰 | 按下不移动、不遮挡文字；与浏览器 CSS 验证区分 |
| selected | 由真实单选／多选状态驱动 `ChoiceButton`；只改变对应选择外观，保持尺寸和文字 | `aria-pressed` 与业务选择一致，选中和默认几何一致 |
| expanded | 由打开状态驱动选择窗口与 chevron；外部／查看关闭同时恢复 | `aria-expanded` 同步；C40 优先度无箭头例外保留 |
| disabled | 普通按钮共用透明度 0.45；overlay 保留深半透明底和稍淡文字，整个点击框不降至 0.45。两者均停止动作和悬停／按下高亮，保留原禁用条件与平台禁用语义 | 真正不能提交／选择；overlay 在明暗图片上仍可辨认，不能只变灰或仅阻止样式 |
| loading | 沿用原 `loading` 及业务锁定；保留动作名称或清楚的处理中含义，防止重复提交 | 图形、文字不裁切，点击不生成重复记录，失败后输入及原 ID 保留 |
| focus | 浏览器键盘焦点清晰可见，不以页面 CSS 移除；键盘和朗读顺序遵循真实节点 | Tab／确认键及关闭后的焦点可达，不能以 CSS order 改视觉顺序 |

图标按钮必须提供明确 `ariaLabel`，包含动作及必要对象，例如「关闭任务编辑」「创建高优先级任务」「下一月」。图标文字与无障碍名称不要求机械相同，但必须说明同一动作。有可见文字时以可见名称为准，必要时补充对象；不能把底色、旗帜颜色或浮窗位置作为唯一说明。

共用组件透传平台支持的名称、禁用、加载和选择／展开状态；真实业务状态仍由调用者提供。加载时是否允许取消取决于原业务规则，不能在按钮统一时擅自清空草稿、关闭处理中的图片编辑或解除账号守卫。

## 共用组件用法

新增调用明确传入层级、尺寸及必要功能意图；按内容传 `width='content'`，需要填满时传 `width='fill'`。不传宽度保持原调用布局，不擅自覆盖既有 flex／grid 的分配。既有 `compact`、`appearance='danger'` 与旧类名推导仅用于兼容现有页面，显式 `size` 优先于 `compact`；它们不作为新增调用的标准，也不构成所有旧调用已迁移的证据。

`context` 表示按钮所在视觉环境，默认 `default`；图像上的纯图标使用 `context='overlay'` 的共用规格。overlay 统一圆形、深半透明底、高对比图形及悬停／按下反馈，避免透明图标落到照片上不可辨认。禁用时仍保留深底，仅稍淡文字并停止反馈；不沿用普通按钮整体透明度 0.45，以免亮图透出后图形丢失对比。该环境规格与尺寸、功能意图分开；不要在页面上重复写图片移除按钮的底色、圆角或图标颜色。

```tsx
import ActionButton, { ChoiceButton } from '../../components/ui-button';
import CreateButton, { AddSymbol } from '../../components/create-button';
import PageToolbar, { CategoryButton, CategoryRow } from '../../components/page-toolbar';
import SheetActions from '../../components/sheet-actions';

// 页面功能栏：创建属于主要入口，但尺寸仍遵循功能栏场景。
<PageToolbar
  manage={<ActionButton appearance='secondary' size='compact' onClick={openManage}>管理</ActionButton>}
  create={<CreateButton label='创建任务' onClick={openTaskComposer} />}
/>

// 正式表单底栏的后续迁移示例：主／次动作使用同一档位。
<SheetActions>
  <ActionButton appearance='secondary' size='large' width='fill' onClick={closeEditor}>取消</ActionButton>
  <ActionButton appearance='primary' size='large' width='fill' loading={saving} disabled={saving} onClick={save}>保存</ActionButton>
</SheetActions>

// 行内删除：危险意图不会迫使辅助动作变成大号主操作。
<ActionButton appearance='quiet' intent='danger' size='compact' onClick={remove}>删除</ActionButton>

// 图片上的局部移除：环境规格保证照片背景下仍可识别。
<ActionButton appearance='icon' context='overlay' size='compact' ariaLabel='移除图片 1' disabled={locked} onClick={removeImage}>
  ×
</ActionButton>

// 选择项：表达选择，使用所属窗口的尺寸，不与提交动作混用。
<ChoiceButton size='compact' width='fill' selected={value === option.id} onClick={() => select(option.id)}>
  {option.label}
</ChoiceButton>

// 分类继续使用 C53；不额外传入普通按钮颜色或自行修改圆角。
<CategoryRow ariaLabel='分类'>
  <CategoryButton selected={categoryId === 'all'} onClick={() => setCategoryId('all')}>全部</CategoryButton>
</CategoryRow>

// C56 纯加号特例：图形尺寸与触控区域分开。
<ActionButton appearance='icon' size='compact' ariaLabel='创建高优先级任务' onClick={openHighPriorityTask}>
  <AddSymbol />
</ActionButton>
```

示例中的函数与状态由所属业务组件提供。`SheetActions` 的成员是否等分、原删除按钮的位置等遵循实际表单布局，不因示例更改原节点顺序或新增按钮；上方底栏示例表示迁移时的规范，并非本轮已经调整全部底栏。`BackButton`、`CreateButton`、`SelectTrigger` 透传相应尺寸／宽度等规格，优先负责各自默认场景；字段选择和分类封装继续负责其原交互，页面只提供动作、数据、状态和必要布局。

页面 CSS 可以控制父容器布局、按钮所占列、间距、位置、最大可用宽度和同组等高；按钮的字号、字重、状态颜色、圆角、内边距和触控下限由共用组件的档位负责。专用业务组件新增自己的视觉规格时在共享实现中声明，所有调用处同步生效，不在每页写一套外观覆盖。

3. 检查默认／悬停／移开／按下／选中／禁用／加载／焦点；选择与展开属性一致，真实节点顺序与视觉顺序一致，禁用和加载确实阻止重复动作。
4. 页面功能栏检查导航留白及操作顺序；分类检查末项可达；浮窗检查 8px 锚定、完整内容与底部动作；正式底栏检查非零安全区、唯一分隔线、正文不被遮挡。
5. 沿用所属功能的创建、保存、取消、重开、草稿、账号及失败重试回归。按钮重构不能改存储键、ID、优先度、原记录或提交时机。
