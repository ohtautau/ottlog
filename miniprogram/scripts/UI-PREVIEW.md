# 小程序界面回归预览

在 `miniprogram` 目录执行 `npm.cmd run test:ui`。

C51 的页面功能栏与分类行单独运行 `npm.cmd run test:toolbars`（`--toolbars`）。读取十个实际页面，四尺寸测量真实动作顺序、右对齐、40px 触控、14px 文字、导航边界、独立分类行与滑动末项；检查首页输入宽度大于 120px、习惯管理往返和文章分类／排序／筛选。原页面交互继续运行相关套件。浏览器 `ScrollView` 的 `scrollIntoView` 只改变当前容器的偏移，避免 DOM 原生方法滚动祖先使平台导航遮挡按钮；返回检查须量按钮相对 `.preview-content` 的位置，不能仅以浏览器视口中的可见比例验收。

脚本使用已有 esbuild、React 和 Playwright，读取真实页面源码，将 Taro 基础组件、存储、API 和页面生命周期适配到浏览器，按 750 设计宽度转换样式，并绘制近似的系统导航与底部 tabBar。截图输出到 `miniprogram/test-results/ui-preview`。

主页快捷方式可单独运行 `npm.cmd run test:home-shortcuts`，覆盖右上角两个图标、原布局二维拖动排序、边缘自动滚动、功能勾选、名称与样式、取消与恢复默认、保存后刷新、存储失败和导航，并比较进入排序前后的卡片截图与全部入口的大小和内容。浏览器将右键事件映射为原生长按，并使用 DOM 矩形适配节点查询；真实微信手势仍需在开发者工具或手机检查。

首页移除领域进展后的两屏导航运行 `npm.cmd run test:home-navigation`；旧 test:home-overview／test:summary 及 --home-overview／--home-summary 保留为兼容入口。检查原概览无挂载、首屏与全部入口直接相邻、按钮往返、首页不为旧概览读取领域／习惯和 growth 快捷入口进入领域主界面；test:home-shortcuts 保留布局／排序／持久化检查，test:screens 与 test:page-snap 验证两屏高度与前后、取消、水平手势。领域完成数、共享进展和账号回归继续使用 test:domains 与纯逻辑入口。C50 的领域主界面验收量每行两张等宽卡、默认八域完整可见、长期／短期目标内容无节点及每卡一条原进展线；管理四项操作按两行两列，详情目标与共享习惯流程保留。

`npm.cmd run test:growth` 继续检查旧成长存档在统计中的展示、归档领域、共同刻度与期间边界、未来记录过滤及账号隔离；首页不再提供小／中／大进步录入。完整统计功能使用 `npm.cmd run test:statistics` 检查六类数据、原页面分析移出和入口返回。以上预览覆盖 360×844、375×667、430×844、768×1024，不能代替微信环境验证。

习惯页可单独运行 `npm.cmd run test:daily`，覆盖双列八卡可视区、分类切换、内部滚动、分类内排序与保存、取消拖动、跨可视区拖动、两个最久未打卡的提醒，以及原有打卡、感想、创建和日历操作。`node scripts/check-habit-order.cjs` 验证未打卡优先、长期历史记录、暂停与今日完成排除，以及排序时保留隐藏和新增习惯。

覆盖今日入口、任务录入/完成、便签编辑/预览/置顶、番茄钟暂停返回恢复、打卡与日历、选餐记录、九步选境结果与回看、营养记录保存、账号同步及访客隔离；保留博客格言、筛选排序、Markdown、收藏、留言和退出检查。不同手机与平板宽度检查渲染错误和非预期横向溢出。

所有数据与账号均为内存 fixture，任何请求都不会触达真实后端。纯逻辑缓存与时钟测试另见 `npm.cmd run test:logic`。

弹层底部回归使用 `npm.cmd run test:sheet-footers`（`--sheet-footers`），已纳入 `verify`，覆盖任务日程、习惯详情与编辑在原生导航页和普通详情页的底部间距、单一分隔线及内容可达性。浏览器样式将底部 `env` 适配为默认 0px 的 `--preview-safe-area-bottom`，该检查显式设为 34px，避免零安全区掩盖重复留白；这是隔离布局模拟，不能当作原生安全区验收。

C32 的习惯详情默认视图验收使用真实共享日历的详情模式及标题／备注组件，几何检查由 `check-habit-detail-layout.cjs` 统一实现，供底部回归、习惯及领域交互脚本调用。在未滚动状态测量四项统计、日历面板、最后日期格、图例及日志／专注按钮，均须处于可见内容区且高于固定操作栏；联合覆盖 375×667、60 字标题、240 字备注、25 分钟专注及非零安全区，日期只读行至少 30px、按钮至少 40px、长标题正文宽度大于 120px。详情尺寸为 `height: min(620PX,100%)`、`max-height: 100%`；超过 32 字的标题默认最多两行并以旋转箭头展开原文，超过 48 字或多行的备注提供同类阅读入口，原文与编辑表单常显备注保留。检查摘要／日志展开收起后恢复默认及取消保留数据；仅有 42 格 DOM 计数、容器边界或无横向溢出不足以证明默认完整显示。

这是 React 布局与交互回归，不等同微信开发者工具或真机验收。原生键盘/Picker/RichText、分享、原生系统导航、底部安全区与真实网络仍需微信中检查。脚本不启动或修改微信开发者工具。

C49 的记录进展回归包含在 `npm.cmd run test:entry-creation`：真实首页／领域列表／详情入口打开三种创建模式，检查正上负下两个共享 Markdown 编辑框、默认无内滚及控件完整可见、标签到输入框的实际 8px 间距、书写／预览／图片、仅正／仅负／两框／纯图片保存、切换及关闭刷新保留、未分类。360px 额外检查本机失败后同 ID 重试、图片失败和处理时账号变化；`test:domains` 保留目标／共享习惯与原记录删除回归，`test:sheet-footers` 在模拟 34px 安全区验证三种创建模式所在的导航页和详情页底部。所有图片与账号为隔离 fixture，不连接真实数据。

标签行间距运行 `npm.cmd run test:tag-row-spacing`（`--tag-row-spacing`），已纳入 `verify`。检查真实共享组件的空／单个／短／长标签、两位数选择数量与动态选项，在四种尺寸测量最后常用标签到展开按钮的间距、单行边界及触控大小，并验证浮窗中的完整标签与多选同步。示例路由仅存在于此浏览器检查，不注册到小程序或保存工具数据。
