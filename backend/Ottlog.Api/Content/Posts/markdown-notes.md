这篇示例展示博客支持的常用 Markdown 排版。**加粗强调重点**，也可以用 *斜体* 表达语气。

## 一个清晰的结构

1. 先说明你想回答的问题。
2. 再给出具体的过程或例子。
3. 最后记录还没有解决的疑问。

### 记录代码

使用三个反引号包围代码，并注明语言：

```typescript
type Note = {
  title: string;
  published: boolean;
};

const firstNote: Note = {
  title: "你好，Ottlog",
  published: true,
};
```

行内代码如 `published` 适合解释变量和文件名。很长的代码行可以在代码块内横向滚动，不会撑宽手机页面。
