这是 Ottlog 的第一篇示例文章，也是这个小空间的起点。你可以直接修改这份 Markdown，把它替换成自己的故事。

## 为什么要写博客

每天都会遇到一些值得记下的事情：终于理解的一段代码、散步时冒出的想法，或是一本书中让人停下来的句子。

把它们写下来，是给未来的自己留一条线索。

> 不必等到想清楚所有事情才开始。记录本身，就是思考的一部分。

## 从最小的一步开始

- 在电脑上舒适地浏览文章。
- 在手机上也能读到同样的内容。
- 用 Markdown 写作，让内容容易迁移。

## 内容与界面分开

文章放在后端的 `Content/Posts` 目录，文件名决定文章地址。比如这篇文章对应 `/posts/hello-ottlog`。网页通过 API 获取文章，后续的小程序也可以读取相同内容。

```text
backend/Ottlog.Api/Content/Posts/hello-ottlog.md
web/src/app/posts/[slug]/page.tsx
```

接下来可以先写几篇真正想分享的文章，再逐步增加后端内容接口和管理功能。

## 留一点余地

这个博客会慢慢变化。今天先让它成为一个能安静阅读、认真表达的地方。
